# 주인공(서고 소환자) 디자인 시트

작성: 안아트, 2026-11-01. 프롬프트 정의는 `docker/gemini/protagonist_style.mjs`에 있다. 공통 스타일 상수는 `style_guide.mjs`에서 가져온다.

## 1. 콘셉트
- 주인공은 서고에 소환된 플레이어의 분신이다. 기록 바깥의 인물이라 어느 시대·문화권에도 속하지 않는다.
- 디자인 공식은 **현대/중립 복식 + 서가 기록 공명 장비**이다.
  - 현대층: 흰 셔츠, 짙은 회색 바지, 갈색 가죽 벨트와 부츠.
  - 서가층: 짙은 남색 하프 코트에 고서 표지 모서리 모양의 각진 금색 제본 테두리를 두르고, 왼쪽 어깨에 크림색 책갈피 리본(V컷)을 단다. 왼손목에는 청록색 서표 팔찌(공명 표식)를 차고, 허리에는 놋쇠 걸쇠가 달린 고서 가방을 찬다.
- 시오리(안내자)와의 관계: 같은 남색과 금색 계열을 써서 서고 소속감을 준다. 시오리는 군사 예복·견장·모노클·은청색 머리이고, 주인공은 견장 없는 하프 코트와 현대 셔츠로 차별화한다. 은청색 머리는 시오리 전용이라 주인공에게 쓰지 않는다.
- 공명 색 **청록(#3FD6C8 부근)**은 주인공 전용 상징색으로 쓴다(팔찌, 검날 테두리, 중장갑 방패 원판). 세계관에서 기록 공명/복원의 시각 언어로 재사용할 것을 권장한다.
- 금지 사항: 글자·문자 장식, 마젠타·분홍·보라(크로마키 충돌), 투구(얼굴 정체성 보호), 미성년 외견, 노출.

## 2. 선택 얼굴 6종 (계정 생성 시 성별별 3종)
| code | 콘셉트 | 머리 실루엣·색 | 피부 | 눈 |
|---|---|---|---|---|
| male_a | 정통파 | 짧고 흐트러진 흑발 | 밝음 | 짙은 갈색 |
| male_b | 냉철파 | 뒤로 넘겨 짧게 묶은 애시 블론드 | 흼 | 회청색 |
| male_c | 호쾌파 | 옆을 친 흑 곱슬, 윗부분 볼륨 | 짙은 갈색 | 황갈색 |
| female_a | 활발파 | 턱선 헤이즐넛 단발 | 밝음 | 초록 |
| female_b | 단아파 | 허리까지 오는 순흑발과 귀 옆 땋은 머리 | 흼 | 적갈색 |
| female_c | 당찬파 | 높게 묶은 구릿빛 적동 포니테일, 주근깨 | 그을림 | 청록 |

구분 원칙: 같은 성별 3종은 **머리 실루엣(길이·형태), 머리색 명도, 피부톤**이 서로 겹치지 않게 한다. 64px 스프라이트에서도 구분되어야 하기 때문이다.

## 3. 표정 (portrait 4종 우선)
neutral / smile / determined / hurt. 자세·구도·의상은 neutral과 같게 두고 표정만 바꾼다. 없는 표정은 neutral로 폴백한다.

| class | 장비(기본 복장 위에 추가) | 레이아웃 견본 |
|---|---|---|

| archer | 짧은 남색 어깨 망토(후드는 내림), 장궁, 등 화살통 | dir64_archer |

## 5. 캐릭터 일관성 프롬프트 전략
1. **앵커 1장 텍스트 생성**: male_a.neutral과 female_b.neutral은 텍스트만으로 만든다. 남녀 앵커를 따로 둔 이유는, 1차에 여성을 남성 앵커 참조로 만들었더니 어깨·체격까지 복제되어 중성적으로 나왔기 때문이다.
2. **같은 성별 neutral**: 앵커 raw를 참조하되 "의상·그림체·구도만 따르고 얼굴·머리·피부·체격은 따르지 말 것"을 명시하고, 얼굴은 텍스트로 지정한다. 이렇게 하면 의상과 화풍은 통일되고 얼굴만 바뀐다.
3. **표정 variant**: 자기 neutral raw를 참조하고 "표정만 변경"한다(시오리 6표정과 같은 방식).
4. **전신 일러스트**: 자기 neutral raw를 참조해 전신으로 확장한다.
5. **기본 스프라이트 시트**: 참조 1은 병종 3x3 방향 시트 견본(배치·도트 크기·등신만), 참조 2는 정식 neutral 초상화 PNG(얼굴·머리·복식·색)이다. 영웅 v4와 같은 규칙이다.
6. **클래스 시트**: 위 두 참조에 **같은 얼굴의 기본 시트 raw**를 참조 3으로 추가한다. 머리·피부·코트 색·도트 크기는 기본 시트에 고정하고 클래스 장비만 덧붙인다(초상화-스프라이트 1:1 기준 유지).
7. 각 얼굴의 고정 묘사(`FACES[*].desc/sprite`)는 모든 프롬프트에 그대로 반복 삽입한다. 프롬프트 문구를 바꾸면 6종 전체를 재생성해야 한다.

## 6. 클래스 표현 방식 결정 (비용·품질)
- 오버레이 레이어 방식(기본 시트 + 무기·갑옷 레이어 합성)은 **채택하지 않는다**. AI 생성 도트는 12프레임×4방향에서 손 위치와 몸 윤곽이 프레임마다 달라 별도 레이어를 픽셀 단위로 맞출 수 없다. 갑옷은 실루엣 자체를 바꾸고, 기병은 말이 필요하다.
- 채택: **클래스 변형 시트 6×5=30장**(1장=1호출, 기본 시트 참조). 비용은 얼굴당 6호출(기본 1 + 클래스 5)이다.
- 폴백: 클래스 시트가 없으면 같은 얼굴의 base 시트를 쓴다.
- 결과(2026-11-01): 6 base + 30 클래스 시트를 전부 제작했다. 시험(male_a 5종)에서 얼굴 정체성이 유지되는 것을 확인한 뒤 전량 생성했고, 재생성은 3회(무기 누락·방향 오류)였다.
- 적 팀색: 기본 스왑(hue 185–265, s≥0.22)을 쓰면 검은 머리의 푸른 하이라이트까지 빨강으로 바뀌어 얼굴 정체성이 깨진다. 그래서 `protagonist_facing.json`에 `enemy_swap.min_s=0.43`을 넣어 남색 코트만 스왑한다.

## 7. 규격
- 초상화: 896x1200 RGBA PNG(3:4, 2K 생성 → 크로마키 알파 → 1200 높이). 영웅·시오리와 같은 규격이다.
- 전신: 9:16 생성 → 알파 → 높이 1600 PNG.
- 스프라이트: 192x256 시트(64px 프레임, 3열 walk1/idle/walk2 × 4행 down/left/right/up), 알파 0/255, 32색, x1/x2(nearest), ally/enemy(파랑→빨강 스왑 + 발밑 받침). 영웅 v4와 같다.
