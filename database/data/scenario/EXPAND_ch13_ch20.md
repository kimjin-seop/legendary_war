# 서가 확장 파일럿 인계서: ch13 황산벌 s4~s10 / ch20 나가시노 s4~s10

작성: 송서사 (2026-11-03). 대상: 임밸런(스테이지 JSON), 맵디자이너(맵), 박백엔(시드·NPC_NAMES), 안아트(초상).
근거 표기는 이 문서에만 둔다. 대사·화면에는 사실/각색 표기를 넣지 않았다.

## 0. 공통 원칙
- 기존 코드(s1~s3, open/end) 불변. 신규는 후미 추가, `rules.optional=true`(숨은 종장 해금 필수 제외).
- 시오리는 신규 스테이지 pre/post/cues에 0줄. 서고 장면은 기존 open/end 그대로.
- 주인공 기여점(전투 판정과 연결)은 스테이지마다 하나: 신호 지점 도달 -> 플래그(`*_up`) -> 증원/보정/승리 조건.
- zone_ref 이름은 제안값. 임밸런이 맵 태그와 다르게 정하면 cue 쪽 `zone_ref`를 맞추겠다(알려 주면 즉시 수정).
- 장면 파일: `database/data/ch13_hwangsanbeol.json`, `database/data/ch20_nagashino.json` (scenes + battle_cues + speaker_profile 반영 완료).
