# 게임 내 텍스트 작성 규칙 (한 페이지)

작성: 송서사 / 2026-11-01 / 계기: 옥포 개전 캡션에 작가 메모('각색했다', '기록상 표기', '일본 측 대사는 없다')가 그대로 노출된 사고

## 1. 대원칙
게임 안에 보이는 문자열(`text`, `short`, `caption`, `prompt`, `label`, `hint`, 시오리·영웅·NPC 대사)은 **세계 안의 말**만 쓴다. 제작 사정, 고증 사정, 데이터 상태를 설명하는 문장은 화면에 나가면 안 된다.

## 2. text에 쓰면 안 되는 것 (금지 목록)
- 각색·압축·축약·재현 같은 제작 용어: "각색했다", "각색으로 표시", "압축했다", "8턴으로 줄였다", "게임 맵에 맞춰", "맵 연출", "시뮬레이션이며"
- 출처·표기 방식 언급: "기록상 표기", "대표로 표기", "(대표 표기)", "자료마다 다르다", "자료 확인이 필요해", "기록을 확인 중", "비워 둔다", "찾지 못한 것으로 둔다"
- 근거 수준 표지: verify, 확인 필요, 확인 중, TBD, TODO, 창작 대사, (수치는 생략), (규모 수치는 표기하지 않음)
- 연출·시스템 지시: "(대사 없음)", "적은 말이 없다", "일본 측 대사는 없다", "NPC로 직접 출전하지 않는다", "사람의 형상이 아닙니다", "이 장은 전부 허구입니다. 실존 인물·사건과 무관합니다"
- 괄호 속 제작 주석 일체. 괄호는 인물 병기(예: 고니시 유키나가(小西行長))나 날짜 병기처럼 **세계 안 정보**에만 쓴다.
- UI 미구현 안내, 화면 요소 이름의 과도한 언급("전장 기록란" 등). 목표 안내처럼 플레이에 필요한 것은 시오리가 자연스럽게 말한다.

## 3. 그 정보는 어디에 쓰나
| 정보 | 넣을 곳 |
|---|---|
| 사실 근거 수준 | `evidence_level` (confirmed / accepted / verify / invented), `source` |
| 창작 여부 | `is_invented` (true = 실존 인물의 실제 발언이 아님) |
| 제작·검수 메모, 각색 사유 | `note` / `dev_note` / `adaptation` (표시 안 함) |
| 연출 지시 | `scene.direction` / `scene_direction` |
| 사람 확인 대기 | `verify: true` (표시 여부는 코드가 판단. 문구 안에 쓰지 않는다) |

`note`, `dev_note`, `adaptation`, `direction`, `meta`, `requires`, `effects.desc`는 **제작용 필드**다. 서버 응답과 FE 화면에 실리면 안 된다(실제 처리 여부는 박백엔·윤프론이 확인).

## 4. 캡션 문체
- 캡션은 서고의 내레이션이다. 현재형 또는 짧은 과거형 평서문. "~다." 종결. 한두 문장.
- 날짜·장소·누가 맞섰는지·무슨 싸움인지만 말한다. 평가는 "~로 꼽힌다" 정도로 한다.
- 불확실한 사실은 단정하지 않고 "~로 전한다"까지만 쓴다. 근거 설명은 쓰지 않는다. 확신이 없으면 해당 문장을 빼고 evidence_level을 verify로 둔다.
- 시오리의 설명은 정중하고 차분하며 건조한 농담이 한 방울 섞인다. 제작자의 변명처럼 들리면 안 된다.
- '만약에' 안내(이순신이 없던 전장 등)는 시오리가 서고 사정으로 말한다. 허용되지만 "각색", "시뮬레이션", "재현" 같은 단어 없이 쓴다.

## 5. 적 측 대사
- 적 지휘관·부장도 스테이지마다 짧은 대사를 가진다(개전, 조우, 퇴각·패배 때 1~3줄). "적은 말이 없다" 식의 처리는 하지 않는다.
- 대사는 모두 창작이므로 `is_invented: true`. 인물 실존·참전 여부의 근거는 `evidence_level`로만 표시한다.
- 화자는 `npc_*` 코드. 서가 11 NPC(`npc_so_*`, `npc_khitan_*` 등)·임밸런 로스터 코드와 충돌하지 않게 `npc_jp_*`(일본), `npc_ink_*`(번진 그림자) 접두를 쓴다.
- 존엄 유지: 조롱, 비하, 민족·국적 고정관념, 학살·잔혹 묘사를 쓰지 않는다. 적도 자기 임무를 지키는 군인으로 쓴다. 승패의 평가는 중립적으로 한다.
- 번진 그림자는 끊어진 문장 조각(……)으로만 말한다.

## 6. 작성 후 점검 (제출 전 grep)
`각색|압축|기록상|표기|대사는 없|대사 없|말이 없|게임 맵|맵 연출|자료마다|확인 중|확인 필요|verify|TODO|TBD|창작|허구입니다|\(` 를 text 값에 대해 검색하고, 남은 항목이 인 월드 정보인지 확인한다.
