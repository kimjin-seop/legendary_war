## 0. 읽는 법

- 줄 번호는 정정 전 원본 파일 기준이다. `S2`=`SCENARIO_02_PROLOGUE_CH1-4.md`, `S3`=`SCENARIO_03_CH5-10_AND_OPEN.md`, `SC`=`database/data/campaign_ch1_scenes.json`, `OL`=`database/data/campaign_ch1_outline.json`, `E15`=`scenario/battle_events_ch1_5.json`, `E610`=`scenario/battle_events_ch6_10.json`, `B15`/`B610`=`BATTLE_EVENTS_CH1-5.md`/`CH6-10.md`(JSON과 같은 내용을 수기로 옮긴 문서라 JSON 정정을 따라 재생성).
- 좌표는 원본 문서 기준 (x,y), 좌측 상단 (1,1). `WATER_RULES_SPEC.md`의 0-based 좌표와 +1 차이.
- 근거 수준: confirmed(복수 출처 일치) / accepted(통설·출처 1종) / verify(사람 확인 필요) / invented(서고 설정·창작) / map(맵 연출, 사료 주장 아님) / rule(게임 규칙 문구, 역사 아님).
- 지형 명칭은 게임 UI 기준을 따른다: 바다, 암초, 항구, 모래, 언덕, 얕은 물(강=여울), 성벽, 성문, 건물, 탑, 허공, 서가 발판(8번 맵 R). 8번의 R은 암초가 아니라 `서가 발판`(통행 가능)으로 변환된다(WATER_RULES 1절).
- 모든 영웅·주인공 대사는 창작 대사(is_invented=true). 사실 서술은 시오리 캡션에만 둔다.
