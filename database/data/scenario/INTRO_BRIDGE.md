# 서가 도입부 개선 설계안: "주인공이 뜬금없이 등장" 해소

작성: 송서사 (2026-11-03). 상태: 설계안 + 샘플 2개(ch11, ch13). 사용자 확인 전이라 JSON 은 수정하지 않았다. 확인 후 전 서가 적용.

## 1. 진단 (현재 구조의 문제)
- 서가 `chNN_open`(서고, 시오리 4줄 이하)은 "{protagonist_name} 님은 ~입니다"라고 신분을 시오리가 통보하고 끝난다. 책으로 들어가는 계기가 없다.
- 첫 스테이지 pre 는 곧바로 주인공이 역사 인물에게 "장군, 정찰 보고드립니다" 하고 보고한다. 그 인물이 이 주인공을 왜 믿는지, 왜 이 자리에 있는지 장면이 설명하지 않는다.
- 튜토리얼 오프닝(시오리 "서고의 기록이 흐트러지고 있습니다. 지휘관님의 도움이 필요합니다")과 이어지는 설정은 이미 있다. 서가 오프닝이 이 설정을 쓰지 않고 있다.

## 2. 설계 원칙 (3단 구성)
1. 계기 (서고, open): 책장에 "비어 있는 자리"가 있고 주인공이 그 자리에 선다. 시오리는 한 줄로 규칙을 알려 준다: 책 속에서 그 자리에 선 사람은 처음부터 거기 있던 사람으로 적힌다. 이 한 줄로 서가마다 신분을 설명할 필요가 사라진다.
   - 오프닝에서 깔 설정은 이미 각 서가의 end 와 맞는다. 예: ch11 end "신호를 올린 사람이 있었다는 것도 적어 두겠습니다", ch12 end "불씨를 옮긴 이름은 아래 칸 끝에 작게", ch13 end 일지가 문서가 된다. 즉 "이름 없는 자리 -> 끝에서 이름이 적힌다"가 서가 공통 호(arc)가 된다.
2. 자리 부여 (본편 첫 장면): 첫 pre 장면에서 역사 인물이 먼저 말을 건다. 인물이 주인공을 필요로 하는 구체적 이유(길을 아는 사람, 일지를 맡을 사람, 글을 읽는 사람 등)를 한두 줄로 밝히면 "왜 여기 있나"가 풀린다.
3. 첫 행동: 인물의 요청에 주인공이 숫자·사실로 답하고(주인공의 말투 정체성), 곧바로 기존 첫 스테이지 대사로 이어진다.

## 3. 포맷 규격
- `chNN_open`: 시오리 3줄 이내(기존 4줄 이하 유지), 주인공 2줄 이상, 총 8줄 이하. 포함 요소 = (a) 이 책장의 빈 자리/지워진 문장, (b) "그 자리에 서면 처음부터 거기 있던 사람으로 적힙니다" 류의 한 줄 규칙, (c) 주인공이 가겠다고 답하는 한 줄.
- 첫 스테이지 pre(`chNN_s1_pre`): 기존 첫 caption 뒤, 기존 첫 인물 대사 앞에 3줄 삽입 = [역사 인물 먼저 말 걸기 -> 주인공 숫자/사실로 대답 -> 인물이 쓸모를 인정하며 본론으로]. 시오리 0줄. 기존 `battle_cues`와 코드 불변.
- 인물이 주인공을 부를 때는 직책("전령", "수행 사자")을 쓰고, 이름 호칭이 필요하면 "{protagonist_name} 님" 규칙을 따른다.
- 대사에 사실/각색/근거 표기 없음. 근거는 이 문서와 outline 에만 둔다.
- 구현 방식(권장 A): 기존 장면의 lines 수정/삽입만 하므로 엔진 변경이 없다. 대안 B: 별도 `chNN_enter`(chapter_start, 서고 밖 bg)를 추가하는 방법은 한 챕터에 chapter_start 장면 2개가 연속 재생되는지 확인이 필요하다(윤프론/박백엔 확인 사항).
- 연출 요청(선택, 미구현이어도 무방): 서고 책장 문이 열려 책 속 풍경으로 넘어가는 페이지 넘김 전환. `sfx_page_turn` 가용 여부 확인 필요.

- 주인공 대사 비율: 두 샘플 모두 주인공 줄이 늘어 비율이 오른다(ch11 open 2/5 = 40%, s1_pre 삽입 1/3, ch13 동일).
- 시오리 줄: ch11 open 3, ch13 open 3 (규칙 4 이하). 스테이지 장면 시오리 0줄 유지.
- 기존 battle_cues, 스테이지 코드, 장면 id 불변. 삽입 3줄은 `s1_pre` 의 lines 앞부분에만 추가.
- 영향 파일: `database/data/ch11_goryeo_khitan.json`, `ch13_hwangsanbeol.json` (샘플 승인 후). 확장 서가(ch15, ch17 등)는 처음부터 이 규격으로 open/s1_pre 를 쓸 예정이며, ch15 의 해당 부분은 승인 후 반영한다(현재 작성한 s5~s10 은 "일지의 앞 장" caption 방식이라 영향 없음).
- 사용자 확인 요청: (1) "책 속에서 그 자리에 서면 처음부터 거기 있던 사람이 된다"는 시오리 규칙 한 줄, (2) 역사 인물이 먼저 말 거는 구성, (3) 구현 방식 A(기존 장면 수정) 채택 여부.
