# 시즌 전쟁 시나리오 legnica 근거 문서

작성: 송서사 (2026-11-04). 대상: `database/data/war/legnica.json` (초안, 박백엔이 등록·시드·테스트). 게임 표시 문자열(이름·note)에는 근거 표기를 넣지 않았고 이 문서에만 둔다. france.json 스키마와 좌표 체계(경도 lon, 위도 lat 십진도)를 그대로 따랐다. 좌표는 현대 도시 중심 근사값이다(1241년 성채 위치와 수 km 차이 가능).

## 시나리오
- code=legnica, shelf_code=ch21(레그니차 서가, 대사 `ch21_legnica.json`). 서가 질문 "등을 보이는 사람은 누구여야 하는가".
- countries: 몽골 제국(aggressive) vs 유럽 연합(defensive). 유럽 연합 안의 폴란드 공국들·실레지아·모라비아/헝가리 방면은 영토로 합쳤고, 튜턴 기사단(분견대 수준, verify)과 보헤미아 왕국(레그니차 당일 접근 후 후퇴, accepted)은 영토 없는 원군.
- map_view lon 12~33, lat 45.5~53.5: 키예프~프라하·부다 포함.
- 시작 구도는 1241년 초(레그니차 이전) 근사. 몽골은 1240년 키예프 함락 이후의 루스 일대를 쥔 상태로 시작.

## 링크 근거
- 루스에서 서쪽으로: 볼로디미르·할리치 -> 산도미에시, 할리치 -> 부다(카르파티아 방면).
- 폴란드 방면: 산도미에시 -> 크라쿠프 -> 라치보르 -> 브로츠와프 -> 레그니차.
- 보헤미아·모라비아: 레그니차 -> 프라하, 라치보르 -> 올로모우츠 -> 프라하.
- 헝가리: 올로모우츠·크라쿠프 -> 에스테르곰 -> 부다.
- 링크는 게임 이동 편의를 위한 단순화이며 역사적 가도와 일치하지 않을 수 있다(verify).

## 확인 필요
- 몽골이 키예프를 capital 로 둔 것은 게임 규칙상의 선택이며 역사적 수도 서술이 아님. 필요 시 capital 지정 변경.
- 튜턴 기사단·보헤미아 supporters 라벨 "원군": 레그니차 참전 정도는 출처별 차이(verify).
- 지명 한글 표기(산도미에시/산도미에르, 라치보르/라치부시, 체르니히우/체르니고프, 볼로디미르 등) 외래어 표기 확인 필요.
- 카르파티아 이남(헝가리)은 몽골이 같은 해 별도 갈래로 진출한 지역이라 한 시즌 지도 안에서는 접근이 단순화됨.
