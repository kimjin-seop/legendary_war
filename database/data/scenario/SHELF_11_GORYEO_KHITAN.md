# 서가 11: 고려-거란 (서희 key / 강감찬)

작성: 송서사 / 2026-11-01 / 상태: 제안(proposal-0.1). 기존 SCENARIO_03 13-2 개요를 5스테이지로 확장한다. 맵은 임밸런이 설계하며 여기서는 지형 키워드만 제안한다. 대사·이벤트 본문은 `shelf_11_scenes.json`, NPC는 `shelf_11_npcs.json`.

## 1. 서가 개요

| 항목 | 내용 |
|---|---|
| 시대 | 993년 1차 침입(안융진, 서희 담판) / 1018~1019년 3차 침입(흥화진, 자주·신은현, 귀주). 2차 침입(1010 개경 함락)은 다루지 않음(피해 서사 회피) |
| 구조 | 한 서가에 두 시대를 나란히 꽂는다(what_if 고지: 서희와 강감찬은 함께 싸운 적 없음) |

| 선택 편성 | 왕건(고려 계열 대사 only_if), 강감찬은 S2부터 NPC 동행, S5 클리어 시 지급 제안 |
| 번짐의 정체 | "서희가 소손녕과 담판해 강동 6주를 얻었다" 한 줄 요약 아래 비어 있는 말, 귀주 "크게 이겼다" 아래 이름 없는 이들의 쪽 |
| 신설 NPC 테마 | 허구 인물 "무명 기록관": 이름 없는 이들의 쪽을 읽는 사람. 주인공의 "먼저 묻는 습관"과 대비 |

## 5. 선택 분기 (결말 불변)

1. 선택 1 (S1 종료 후): 서희의 담판을 "상대의 사정을 먼저 듣는다 / 서희의 논거를 먼저 정리한다". 역사 결과 동일, 주석 문구와 호감 대사만 다름.

## 8. 사람 확인(verify) 목록

1. 서희 담판의 논거·합의 내용(고구려 계승, 압록강 인근 땅, 송과의 단교). 영문 위키는 "송과의 관계 단절·거란에 조공·압록강까지 땅 확보"로 서술, 한국어 문서와 서술 차이 가능.
2. 강동 6주(개별 주명 미확인).
3. 안융진 방어자(대도수·유방)와 직함, 전투 시점.
4. 소손녕=소항덕 동일 인물 여부.
5. 흥화진 수공의 주체·시점(강감찬 직접 지휘 여부), 소배압 총사령 직함.
6. 자주·신은현 협공 세부(영문 위키 본문에 없음).
7. 귀주 전투 연도(1018/1019), 바람 방향 전승, 김종현의 역할.
8. 강민첨 직함.
9. 야율팔가의 실존·역할(확인 전 미사용).
10. 시오리 필적 암시(F6-5)는 SCENARIO_03 복선 번호와 일치하는지 팀장/문기획 확인.
