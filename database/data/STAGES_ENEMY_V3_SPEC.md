### 2.1 부대별 서사·진형 의도와 좌표 규칙
좌표는 `stages_ch1_enemy_v3.json`의 `enemy_squads[].cells`(첫 칸=지휘관)에 확정되어 있다.

## 8. 박백엔용 스키마·시드 가이드 (④)
- 적 편성 입력: `items[].enemy_squads[]`(부대) 또는 호환 평탄 목록 `units_flat_initial[]`(기존 `enemy_presets[].commander + units[]` 확장). 시드는 `cells`를 그대로 배치 좌표로 사용(없으면 기존 BotDeployer 규칙).
- `leader.kind`: hero(영웅 DB 행) / npc(heroes 행 + npc 플래그) / generic(영웅 없음, `display_name_ko` + 병종 + hp_mult). 총지휘관(main)만 kind=commander, 나머지 부대장은 일반 영웅급 유닛(즉사 규칙 대상 아님: **확인 필요**).
- `triggers[]`: STAGES_CH1_SPEC/WATER_RULES 6절의 `stage.triggers`와 필드 호환(`on.turn`, `action:'spawn'`, `side`, `units`는 `squad`로 확장). 보스 페이즈는 `on.boss_hp_pct_lte`(WATER 선택 항목 B8).
- `ai`: 미지원 시 전부 advance 폴백으로 동작(데이터 검증은 값 목록만 허용).
- `apply_main_hold`(옵트인, bool): `enemy_squad` 최상위 `apply_main_hold === true` 이고 최상위 `hold_until_turn`(정수 1~99)이 있으면 main 부대(b0 지휘관 + main 병사)도 그 라운드 전까지 제자리 대기(ArmyBuilder::addGenericSide). 없거나 false 면 main 의 hold_until_turn 은 무시(기존 동작). sub 부대(`squads[].hold_until_turn`)는 이 플래그와 무관하게 항상 적용. 사용처: ch12_s1(문빙 main hold 5). 주의: EnemyV3Adapter 는 현재 main 부대의 hold_until_turn/apply_main_hold 를 enemy_squad 로 옮기지 않아 `game:seed-shelf --update` 재시드 시 소실됨(요청 중).
- `ally_zone_override`: 진주성만 사용. 미지원 시 맵 deploy_zones.a가 성 밖이라 서사 불일치.
- `reward_proposal`/`win_rate_band_target_pct`: 참고 필드(시드 불필요).
- 시드는 code 기준 멱등 병합, 개발 DB에만.
