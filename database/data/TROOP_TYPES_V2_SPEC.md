# 병종 체계 v2 설계 스펙 (9종, 설계 제안 / 미적용)

작성: 임밸런, 2026-11-01. 데이터: `troop_types_v2_proposal.json` (같은 폴더). 모든 수치는 **가정 시작값**이며 신규 병종이 엔진에 없어 시뮬레이션은 불가, 아래 근거는 **코드·데이터 사실 + 산술**뿐이다. 최종 밸런스는 마지막 단계에서 일괄 측정한다. 앱 코드·DB·.env·기존 데이터는 수정하지 않았다.

## 0. 확인된 사실 (현행 코드/데이터)
- `unit_types.json`에 이미 sword, spear, cavalry, archer, **mage, healer**, heavy, flyer 8종이 있다. 신규는 **수병·마물·암살자 3종**뿐이고 마법사·승려(치유사)는 기존 병종의 개편이다.
- `heroes.unit_type`(영웅 지휘관 class)은 부대 병종(`hero_troop_types`)과 별개다. class heavy 영웅이 **11명** 있고(부대 병종 heavy 13명과 다른 집합), mage 16명·healer 14명이 이미 class로 존재한다. heavy 삭제는 두 곳 모두 영향을 준다.
- 부대 병종은 영웅당 1종 고정이며 슬롯 수(Lv1/10/20에 2/3/4) 전부가 그 병종이다(SquadPlanner).
- move_type은 foot/mounted/heavy/flying. 물 타일은 flying 외 전부 통행 불가. 맵 물+여울 비중은 maps.json 4.7%, maps_pack20 5.9%.
- 코스트: 영웅 코스트 + 부대 병종 코스트 합이 `user_level_costs.max_cost`(Lv1 16)에 들어간다.
- 피해식: round((atk x 총배율 - def x (1+방어%)) x 1.2). 총배율 clamp 0.6~1.5, 측/후방 x1.15/x1.30(상한 1.8).

영웅 vs 병사: 병사 = 위 기본값 x 레벨 성장(3%/Lv), 영웅 유닛 = 기본값 + 영웅 보너스(S 기준 +24/6/3 x 병종 보정). 배율이 아닌 가산 구조이므로 신규 병종도 같은 틀을 쓰고, `hero_stat_rules.json`의 `type_bonus_multiplier`에는 naval(보병과 동일 1,1,1)·assassin(아처 계열 [0.8,1.0,0.5]) 행만 추가하면 된다(heavy 행 삭제). 영웅 class로는 신규 3종을 쓰지 않는다(부대 전용).

### 지형 이동 비용/제약
- 보병·창병·기병·궁병·마법사·승려·암살자·마물: 기존 foot/mounted 테이블 그대로. 기병은 산·늪 불가(v1).
- heavy 삭제 효과: 구 heavy 데이터는 산·늪 불가였으나 보병(foot)은 산 3·늪 3으로 통행 가능. 영웅 class heavy 11명과 부대 13명(9명은 보병 이관)의 기동이 늘어난다(이동 3->4 포함).
- 수병(naval) 신규: 물 이동 1·방어 +20, 여울 1·+10, 평지·도로·다리·마을·성 이동 1(방어: 평지 -10, 성 +20), 숲·늪·설원 이동 3, 산·절벽·성벽 불가. 물 비중이 5~6%라 육지 불리를 이동비가 아닌 방어 보정으로 표현했다(이동비로 하면 대부분 맵에서 약병종). 전체 값은 JSON `terrain_modifiers_new_move_type_naval`.

### 특수 규칙 (엔진 최소 구현안)
- 마법사: 방어 30% 무시(E1), 지형 방어 보정은 유지. v1의 mage>heavy 1.25는 삭제(heavy 소멸). 산술: 마법사 대 보병 25 피해(v1 24)로 연속성 유지.
- 승려: 기존 healer와 **통합**(코드 healer 유지, 표시명 승려). 치유 로직(heal 12, 최대HP 15%, 진영 합계 상한 30) 그대로. 별도 monk 병종은 중복이라 비추천. 단 영웅 class "치유사"(허준·이븐 시나 등 의사·학자 14명)가 같은 병종 표시명을 쓰면 "승려"가 어색하므로, 영웅 class 표시만 별도 라벨로 두는 안을 결정 D2로 올린다.
- 마물: **적/이벤트 전용**(playable=false). enemy_presets의 일반 지휘관 unit_type=monster, enemy_extra_troops, 보스·이벤트 스테이지. 가챠·유저 편성 불가. 영웅 매핑 근거가 없으므로 사실 창작 문제도 없다.
- 암살자: 측/후방 배율 {1.25, 1.5}(E2, 상한 1.8 유지). 은신은 선택안(E3: 숲 위에서 사거리 2 이상 원거리 대상 지정 불가). 1차는 E2만 권장.
- 수병: 위 지형 데이터 + 수상전 맵 공급(E4).

### 3-2. 영웅 class heavy 11명 (leonidas, xiang_yu, charles_martel, vauban, socrates, marcus_aurelius, william_i, richard_i, honda_tadakatsu, gyebaek, guan_yu)
sword로 이관. heavy(95/22/15)와 sword(84/28/10) 차이는 HP -11, ATK +6, DEF -5. Lv1 동일 보존안: hp_bonus +11, atk_bonus -6, def_bonus +5(JSON `hero_class_heavy_comp`에 영웅별 before/after). 예: leonidas atk_bonus 2 -> -4(음수, E8 확인). 보정을 안 하면 Lv1이 이만큼 달라진다. 성장률은 가산 후 값에 곱해지므로 Lv1 동일이면 성장 곡선도 동일하다.

### 3-3. 신규 병종 후보(101명 중)
- 채택(근거가 repo 기록에 있음): **이순신(sword->수병)**, **넬슨(sword->수병)**, **주유(archer->수병)**. 모두 hero_profiles/hero_unit_basis/fact_checks에 수군 지휘 기록이 있고 ideal_v2가 naval이다. 이 기록은 웹 재검증을 하지 않았으므로 인간 확인 필요.
- 보류 후보(기존 병종 유지, needs_verify): 수병 - 아르테미시아 1세, 손권, 쩐흥다오, 왕건(혼성), 요시쓰네(기병 유지 권장), 사카모토 료마(군 지휘 아님). 마법사 - 아르키메데스, 메흐메트 2세, 김시민(마법사를 포·술사로 재해석할 때만, D4). 승려 - 휴정·유정(승병은 치유 근거 아님, 보류 권장), 힐데가르트·이븐 시나·허준·호세 리살(부대는 설정부여).
- **암살자: 채택 0.** 역사 영웅의 암살자 부대 근거가 없고(장량 박랑사 등은 폭력 시도라 기존 프로필에서 제외됨), 료마·카이사르 등 피살 인물과의 혼동을 피하기 위해 영웅 매핑에서 제외. 암살자는 일반병/적 편성용.
- **마법사 troop 채택 0** (근거 없는 사실 창작 금지). 마법사는 판타지 병종이므로 일반 모집·적 편성 위주.
- v2 부대 병종 분포(101명): 보병 31, 기병 29, 창병 20, 궁병 18, 수병 3 (v1: 보병 24, 기병 25, 창병 20, 궁병 19, 중장 13).
- **구조 문제(E5):** 고정 병종은 슬롯 전체를 채우므로 승려·마법사·암살자를 고정하면 4기 전원이 지원/유리대포가 된다. 이들을 영웅에 쓰려면 혼성 패턴(`[sword,sword,healer]`)이 필요하다. E5가 없으면 위 후보는 적용하지 않는 것이 안전하다.

- **재사용 우선안 A(권장): 3~6회 호출.** 3종 default 시트 1회씩 + ally/enemy는 기존 팔레트 스왑, 문화권 변종은 팔레트·액센트 변환(0회). 남은 18회 중 3회+재시도 예산 3회.
- 안 B: 8~9회(수병을 korea/china/japan에서 별도 생성). 안 C: 3종 x 6문화권 = 18회(남은 호출 전부, 재시도 0, 비권장).
- 임시: manifest alias(naval->sword, assassin->archer, monster->cavalry)로 FE 먼저 동작 확인. 승려는 기존 healer 시트가 승복 외형인지 안아트 확인. 병종 아이콘 신규 3종.

## 6. 측정 계획 (밸런스 최종 단계 일괄, 지금은 설계만)
1. 엔진 반영 후 병종 라운드로빈(동일 코스트·지형별) 승률 그리드, 병종쌍당 N>=400, 95% Wilson, 동일 시드로 전후 비교. 선공 편향·평균 턴·턴제한 종료율·첫 턴 사살률 병기.
2. 기병 지배력(상성 이득 3개 추가), 필요 시 기병>마법사/승려 소 상성부터 1.0으로 롤백.
3. 암살자 후방 1타 사살 빈도, 마법사 방어무시 효과(E1/E2).
4. 수병 맵별(물 0/5/20%) 승률 편차(물 맵 1~2종 추가 후).
5. heavy 퇴역 영웅 24명(부대 13 + class 11, 일부 겹침 포함) Lv1 동등성, 코스트 감소분(보병 이관 9명) 영향.
6. heavy를 쓰는 stage_02·stage_04 등 스테이지 승률 재측정(목표 대역은 기존 스테이지 문서 기준).

## 7. 사용자 결정 필요
- D1 보병 표시명 검병->보병, 코드 sword 유지(권장) 또는 코드 변경.
- D2 승려=치유사 통합(권장) 여부, 영웅 class "치유사" 라벨을 분리 표기할지.
- D3 마물 용도: 적/이벤트 전용(권장) vs 게스트 허용.
- D4 마법사를 판타지 마법사로 둘지, 포·술사로 재해석할지(역사 영웅 채택 수가 달라짐).
- D5 영웅 class heavy 11명을 sword로 이관할 때 Lv1 보정 적용 여부(권장: 적용, 음수 보너스 허용 필요).
- D6 수병 3명 채택(이순신·넬슨·주유)과 보류 후보 처리, 레오니다스·이에야스의 보병 vs 창병.
- D7 혼성 부대 패턴(E5) 도입 여부(미도입 시 승려·마법사·암살자 영웅 매핑 불가).
- 인간이 확인할 것: 영웅별 사실 근거 문장(웹 미확인), 신규 병종 외형 가독성, 수병이 물 비중 낮은 맵에서 체감 약한지, 기병 체감 지배력.
