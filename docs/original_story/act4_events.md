# 오리지널 메인 4막 ep16~ep20 + 엔딩·에필로그 전투 중 이벤트(cue) 제안·정보 공개·복선 회수 (초안 r2)

r2(문기획 4막 검토 반영, act4_scenes.json version 2, 215 -> 223줄): 서고장=공석(대장상), 교정 담당 책임자가 직무 대행, 결재자 칸 정보를 4-3 post 시오리 한 줄과 3막 끝(a3_end)에 선행. 4-4 pre에서 자기 서명(효력 없음)과 임용 서명(서고장 서명 또는 직인) 구분. 엔딩 서고장 서명은 '열람 목록 등재 요건 충족 시 규정에 따른 자동 갱신'(시오리 사실 한 줄), 서고장 이름은 계속 비공개. 쪽이 정체는 4-5 post에서 쪽이가 '이 책의 첫 장 자리에 있던 사람'이라 말하고 지음이 열람실의 추정(act1 a1e3_post)을 확정으로 정정. 주인공 엔딩 회상 한 줄. 허준 에필로그는 '서가가 있든 없든 내 장부에 있겠소'로 수정(서가 예고 근거 없음). 7층은 4-3 pre에서 '지도에 없다'로 한정(대장에는 한 줄 있음). 사자 직인(임용용)과 분실 직인 구분과 반납 한 줄. 가칭 열람 정의(a4_open)와 검증 문구(4-5 pre), '임시 표기는 이름이 정해지기 전에도 읽혔다는 증거'로 일관. 교정관 논리 3막-4막 통일('읽는 이를 속인다 -> 읽는 사람이 끊긴다 -> 사라진다')과 수용 줄(전제 반증, 정리 서식 수정, 정리 목록 세 장 전부 폐기). 미복원 서가 중간 갱신(4-3 post '열하나 중 둘은 낱장 번호가 처음부터 없음'). 4-1 post 지명 정정, 대사 내 편 번호 메타 표기 제거, 지음 동행 이유 한 줄(4-3 pre) 및 예고 통합, 양초지기 추가, 살라딘·잔 다르크 4-4 한 줄, e4-E2·e4-E4 이벤트 조정.

작성: 송서사, 2026-11-03. 짝 파일: `docs/original_story/act4_scenes.json`(version 1). 기준: ORIGINAL_STORY_SYNOPSIS r2 2·3·4·5절, act1~3 데이터(r3·r2·r2), CUTSCENE_SPEC(say/camera/sfx/shake/move/fire/set_flag/spawn/terrain_change/retreat 구현됨, 승리조건 hold_zone·unit_survive 구현됨, `on`=battle_start/turn:N/when). 전부 오리지널 가상, 대사는 창작 대사. 좌표는 맵 확정 전이라 `[?]`. 효과음은 확인된 키만(`sfx_fire`, `sfx_battle_tick`, `sfx_battle_rumble`, `sfx_battle_fall`, `sfx_aura_pulse`, `sfx_move_step`, `sfx_battle_roar`, `sfx_turn_enemy`). 시야 제한·선택 분기·이름 입력은 미구현이므로 대사로 약속하지 않고 연출 요청으로 분리했다. 대사 주도 판단 장면(e4-E3 지음 선택, e5-E3 교정관 논리, e5-E5 쪽이 이름)은 선택 UI 없이 자동 진행이다.

## 4. 근거 수준·점검

- 전 215줄 is_invented=true(invented 100%). confirmed 0건. 역사 골격은 장면 evidence에 구분: accepted(12세기 시리아 대상로, 우물을 마디로 한 대상 행렬 일반론), verify(살라딘 출생 1137년경·몰년 1193, 우물가 중재 장면은 각색으로 사료 근거 없음, 대상로 우물 분쟁은 일반화한 가상 설정).
- 실존 인물은 살라딘뿐(4-2). 대사는 전부 창작이며 호칭 '물 나누는 자'는 사양시키고 '나눌 수 있는 자리에 서 있었을 뿐'이라는 겸양 한 줄로 제한. 종교 갈등 단죄·미화 없음. 허준·잔 다르크는 앞 막 합류 인물이며 4막 대사는 역할 범위(진료, 호칭 이야기) 안에서 창작.
- 시오리 '메우다·채우다(빈 곳 의미)' 계열 0건(Grep으로 대사 본문 확인, `_note`에만 용어 설명으로 등장). 시오리는 사실 진술(인물 카드, 규정 9조, 서가 폭)과 목표 안내 위주이며 자기 과거·글씨·정체 암시 0건. 엔딩 마지막 쪽 '그다음 쪽은 열람 등급 밖'은 정체 암시가 아니라 열람 등급 안내로 한정.
