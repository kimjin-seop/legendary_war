# ch999 종장 "서고의 마지막 장"(가칭) 스테이지 아웃라인

- 작성: 송서사, 2026-11-03. 대사 본문: database/data/ch999_finale.json (장면 id 와 stage_code 는 이 문서와 동일).
- 기준: preview_shelves_acceptance.md 0-1절(옴니버스), 7절(종장, 7-9 잠정 결정: A안 4스테이지), docs/CUTSCENE_SPEC.md 6~12절.
- 성격: 서고 안의 가공 장면이다. 역사 사건을 다루지 않으며 각 서가 본편과 인과로 이어지지 않는다. 지명 표기 규칙은 역사 지명이 없으므로 "서고 안 구역 이름"(복도, 신호의 방, 이름 없는 칸, 마지막 장)으로 한다. 메인 4막의 결론(서고장 공석, 미복원 서가 2곳 등)은 건드리지 않고, 지음·쪽이·교정관의 기존 말투만 짧게 빌린다(지음의 끝맺음 "제가."·"추정입니다" 사용 횟수 제한 항목은 이 장에서 쓰지 않았다).

## 1. 핵심 영웅 카드와 주인공

- 이 장에는 key 영웅이 없다. 대신 모든 서가의 key 영웅 15명과 메인 인물이 조연으로 한 번씩 등장한다.
- 주인공: 서고 원정대 연락 장교. 서가마다 다른 신호 도구(봉수, 횃불, 깃발, 북, 호각)를 다뤄 본 사람. 모든 스테이지의 판정에 연결된 행동을 한다.
- 장 질문: 전한 말은 어디에 남는가. 답: "자리만 적힌 칸"을 읽어 돌려주고, 마지막 칸에 한 줄을 적는다.

## 4. 스테이지 카드 (주인공 시점)

### ch999_s1 겹쳐진 복도
- 내가 하는 일: 책장 번호 표지 세 곳을 순서대로 읽는다(읽는 동안 한 라운드씩 서 있어야 한다).
- 목표: win_mode "all". 번호 표지 3곳 in_zone 순차 달성(flag `marker_1_read`~`marker_3_read`) + 지워진 줄 소탕. 패배: 주인공 쓰러짐.
- 기여 지점: 표지 3곳 도달이 길 열림(terrain_change 또는 spawn)의 선행 조건.
- 아군 NPC: 이순신, 허준(동행 유닛 또는 cue 화자).

### ch999_s2 신호의 방
- 내가 하는 일: 신호 타일 5곳(봉수, 횃불, 깃발, 북, 호각)을 서쪽부터 순서대로 점화한다.
- 목표: win_mode "only". `signal_5_up` flag 가 서면 승리. 순서를 어기면 flag 가 초기화된다(set_flag false)는 판정은 박백엔 확인 후 단순화 가능. 대안: 순서 없이 5곳 도달.
- 기여 지점: 신호 5곳 도달 자체가 승리 조건이다. 지워진 줄이 신호 타일을 점거하면 점화가 막힌다(적 유닛이 서 있는 칸은 진입 불가).
- 출연: 주유, 알렉산드로스, 강감찬, 칭기즈 칸(앞), 살라딘, 노부나가, 스키피오, 을지문덕(뒤).

### ch999_s3 이름 없는 칸
- 내가 하는 일: 낭독 자리 3곳에서 각 두 라운드 서서 장부를 읽는다.
- 목표: win_mode "all". sub_objectives hold_zone 3곳(각 2턴) + 지워진 줄 소탕. 패배: 주인공 쓰러짐, 낭독 자리 점거 시 해당 라운드 무효.
- 기여 지점: 낭독 자리에 서 있는 것이 곧 판정(hold_zone).
- 출연: 김유신, 잔 다르크, 바이다르, 바부르, 윌리엄, 카를 마르텔, 쪽이, 교정관, 지음.

### ch999_s4 마지막 장
- 내가 하는 일: 백지의 힘을 절반 이하로 꺾은 뒤 마지막 칸 타일에 닿아 한 줄을 적는다.
- 목표: win_mode "all". 보스 "백지" defeated + `last_line` in_zone latch. cue: 보스 hp_pct_lte 50 → set_flag(`last_line_open`) → 마지막 칸 타일 활성. 패배: 주인공 쓰러짐.
- 기여 지점: 마지막 칸 도달이 승리 조건의 절반.
- 출연: 이순신, 잔 다르크, 허준(pre), 지음, 교정관, 바하 앗딘, 쪽이(post).
