# 준비 중 서가 9개 인수조건 (문기획)

1절(서가 개요)·2절(제작 순서)·4절(총괄표)·5절(결정 필요)은 문기획 보고 원문 그대로다. 0-1절과 3절은 서사 원칙 확정 후 문기획이 다시 낸 판으로 교체·추가했다. 결정 사항과 옴니버스 기준은 맨 아래 부록에 둔다.

## 0. 공통 전제
- **모범 구조**: ch23 아웃라인(`docs/original_story/ch23_hastings_outline.md`)을 따릅니다. 서가 1개는 오프닝 장면, 스테이지별 pre/post, 엔딩 장면, 스테이지 카드, 등장인물 표, 맵 요구서로 구성합니다.
- **스테이지 규칙**: 서가당 3~5개입니다. 전투 승패는 CUTSCENE_SPEC 6~12절 범위(capture, defeated, in_zone, unit_survive, survive_turns, protect_tiles)만 씁니다.
- **엔진 연출 범위**: route, tile_tags, terrain_change, reinforce, triggers, cue는 ch23과 ch24 스테이지 파일에서 쓰이는 것을 확인했습니다.
- **엔진 확인 필요 (박백엔)**
  - 불 번짐(fire) fx가 있는지. ch23에는 water_rise만 확인했습니다.
  - 다리 붕괴 같은 턴 기반 terrain_change가 되는지
  - 영웅이 연출로 전사·퇴장하는 컷이 되는지
- **용어 규칙**: 지도·대사 라벨은 당대 국호만 씁니다. 사실·가설·근거 수준 표기는 대사·화면·문서에 넣지 않습니다.
- **초상 집계 기준**: "신규 초상"은 로스터 NPC 중 초상이 없는 인물입니다. heroes.json 영웅(풀 영웅)과 `portrait.<code>`가 이미 있는 NPC는 제외했습니다.
  - 풀 영웅 일부(예: 오다 노부나가)는 초상 파일 존재를 전부 확인하지 못했습니다(확인 필요).
  - "필수"는 대사·스테이지 화자와 지휘관만 센 숫자이고, "선택"은 이름만 나오는 인물입니다.
- **스테이지당 맵**: 1장을 기본으로 보되, 기존 맵 템플릿 재사용 가능성은 맵디자이너가 판단합니다.

## 0-1. 서사 원칙

서가는 시나리오로 안내하는 파수꾼(시오리)일 뿐이고, 서가 안에서는 주인공이 중심이 되어 역사적 인물과 스토리를 풀어간다.

| 규칙 | 내용 | 확인 방법 |
|---|---|---|
| 서고 장면 수 | 서가당 2개만 둔다. 입장(`chN_open`)과 퇴장(`chN_end`)이며, 스테이지 pre/post와 cue에는 서고 장면을 두지 않는다. | 서고 bg 장면이 `chapter_start`와 `chapter_end` 두 개뿐인지 확인한다. |
| 서고 대사 상한 | 장면당 8줄 이하, 시오리 발화는 장면당 4줄 이하, 서가 전체 시오리 발화는 8줄 이하다. 챕터 소개·질문 제시·마무리만 말한다. | 대사 파일에서 `"speaker": "shiori"` 줄 수를 센다. |
| 스테이지 내 시오리 | pre/post/battle_cues에서 시오리 발화는 0줄이다. 시대 배경은 캡션 cue, 주인공 대사, 역사 인물 대사로 푼다. | 위와 같은 방법으로 센다. |
| 주인공 중심 | 모든 스테이지 장면에서 주인공의 선택·행동·대사가 중심이다. 주인공은 관찰자나 질문자로만 쓰지 않는다. | 스테이지마다 주인공 발화가 있고 아래 "기여 지점"이 있는지 확인한다. |
| 역사 인물의 위치 | 역사 인물은 주인공과 관계를 맺는 조연이다. 상황의 계기 또는 해결에 주인공이 기여하는 구조로 쓴다. 연속 독백은 3줄 이하로 한다. | 장면마다 인물 발화 직후 주인공 반응이나 요청이 있는지 확인한다. |
| 주인공 기여 지점 | 스테이지마다 판정에 연결된 주인공 행동을 최소 1개 넣는다. 예: 신호 타일 도달 시 증원 도착, 정찰 서브 목표, 인솔한 NPC의 in_zone. | 스테이지 카드에 "내가 한 일 → 판정 변화"가 적혀 있는지 확인한다. |
| 서술 시점 | 스테이지의 목표·패배·서브 목표·컷을 모두 주인공 시점("내가 ~한다")으로 쓴다. | 카드 문장의 주어가 주인공인지 확인한다. |
| 비중 목표 | 본편(open/end 제외)에서 주인공 발화 비율이 25% 이상이다. | 6-1절 현황표와 같은 방법으로 센다. |

## 3. 첫 3개 상세 인수조건 (주인공 시점)

### 3-1. ch12 적벽의 불길 (208년 겨울, 4스테이지)

- **엔딩 질문**: 같은 물길에서 서로 다른 지략을 이은 사람은 누구인가.

| 스테이지 | 내가 하는 일과 목표 | 패배 | 서브 목표 | 주인공 기여 지점 | 엔진 |

## 7. 종장 (숨은 스테이지) 인수조건

팀장 잠정 결정(되돌리기 쉬운 쪽)은 7-9절에 있으며, 아래 본문의 후보 표기보다 우선한다.

### 7-0. 기존 구조 확인
- **해금 방식**: 스테이지 해금은 `stages.prerequisite_stage_id` 하나뿐입니다(`BattleService.php:57-67`: `clear_count>0` 여부). 선행 스테이지를 하나만 걸 수 있어서, "전체 클리어" 조건은 현재 구조로 표현할 수 없습니다.
- **클리어 기록**: `user_stage_progress`(user_id, stage_id, clear_count, best_stars, cleared_at)가 있고 `BattleService.php:1159-1197`에서 기록합니다. 이 테이블이 판정의 근거가 됩니다.
- **영웅 지급**: 장면 데이터에 `unlock_hero` 필드가 있습니다(예: `ch23_hastings.json`). 영웅 카드 연결은 이 필드를 활용합니다. 실제 지급 처리 위치는 확인 필요입니다(`BattleService`).
- **운영 DB 변경**: DDL이 필요한 항목은 박백엔 구현 후 사용자 승인 아래 반영합니다.

### 7-1. 목표와 사용자 경험
- 모든 캠페인 서가와 메인 4막을 클리어하면 숨겨진 종장 서가가 열리고, 오리지널 스토리 1편을 플레이할 수 있다.
- 종장도 옴니버스 규칙을 따른다. 서고(시오리)는 입장·퇴장에서만 짧게(서가당 2장면, 각 8줄 이하, 시오리 4줄 이하) 말하고, 본편은 주인공이 중심이다. 클리어하면 영웅 카드를 획득한다.
- 종장이 열리기 전에는 서가 지도에 존재 암시만 있고, 열리면 일반 서가와 같은 방식으로 진입한다.

### 7-7. 인수조건 (테스트 가능)
1. active 서가 전체와 메인 4막을 모두 클리어하기 전에는 종장 진입 요청이 서버에서 거부된다(FE 숨김만으로 판단하지 않는다).
2. 모두 클리어한 계정은 종장 스테이지를 시작할 수 있다.
3. 새 active 서가가 추가되면 종장 해금 집합에 자동 반영된다(이미 해금한 유저는 유지).
4. 종장 클리어 시 영웅 카드를 1회 지급하고, 재클리어로 중복 지급되지 않는다(중복 시 조각 지급 규칙 적용).
5. 종장의 서고 장면은 입장·퇴장 2개뿐이고 각 8줄 이하(시오리 4줄 이하)다. 스테이지 내 시오리 발화는 0줄이다.
6. 종장 스테이지마다 판정에 연결된 주인공 행동(기여 지점)이 1개 이상 있다.
7. 잠김 핀은 이름·위치를 드러내지 않는다.

### 7-8. 위험
- **서가 추가 시 해금 기준 변동**: 이미 종장을 연 유저와 아직 못 연 유저의 형평성 문제가 있다.
- **선택 스테이지**: 필수로 포함하면 진행을 막을 수 있다. 제외하면 "전체 클리어"의 의미가 약해진다.
- **가챠 풀 희석**: 종장 영웅이 `campaign_only`이면 가챠 풀에 자동 포함되어 보상 가치가 희석된다.
- **preview 서가의 활성화 시점**: 지금 active가 아닌 ch11~ch17, ch19, ch20이 곧 active가 되면 집합이 7~8개 서가만큼 커진다. 종장 개발을 먼저 하면 임시 집합이 된다.

### B. 서사 원칙 (옴니버스 기준)
- 각 서가는 독립 에피소드다. 챕터 간 이어지는 줄거리는 필요 없다. 서가(시간의 서고)는 입·퇴장 안내만 하는 파수꾼이다.
- 각 세계 본편은 주인공이 중심이 되어 역사 인물과 스토리를 풀어 간다. 영웅 카드(key)가 있어야 캠페인을 할 수 있으므로, 각 서가 outline에 핵심 영웅 카드(key)를 명시한다.
- 서고 장면은 입장(`chN_open`)과 퇴장(`chN_end`) 두 개. 장면당 8줄 이하, 시오리 4줄 이하. 퇴장 장면은 다음 세계로 이어 주는 짧은 전환이다.
- 스테이지 pre/post/battle_cues에는 시오리를 두지 않는다. 이야기상 꼭 필요한 개입은 챕터당 0~2회, 각 3줄 이내의 예외로만 두고, 개입 장면 id는 outline에 따로 표시한다(서가는 질문·힌트·경고만 하고 주인공 대신 해결하지 않는다).
- 스테이지마다 주인공 기여 지점(내가 한 일 → 판정 변화)이 있다. 본편의 주인공 발화 비율은 25% 이상.
- 근거 수준·가설·각색 표기는 대사·화면·문서에 쓰지 않는다. 대사 안에 출처·불확실성 단서도 쓰지 않는다.
