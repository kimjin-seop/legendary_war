## 0. 이 문서가 사용자 지시와 어긋나 보이는 곳 (확인 요청)

1. 지시문의 "쩐 꾸옥 뚜언"(Trần Quốc Tuấn)은 쩐흥다오의 본명이다. 이미 기존 영웅(`tran_hung_dao`)이 있으므로 신규 NPC로 만들지 않았다. 신규 NPC로 의도한 인물이 "쩐 꾸옥 또안(Trần Quốc Toản)"(소년 장수)이라면 그쪽으로 반영(아래 로스터에 `npc_tran_quoc_toan` 포함). 확인 요청.
2. s6 "2차 침입 거점(점령)"은 1285년 반끼엡(Vạn Kiếp) 몽골 야영지 점령으로 해석했다. 1257~58 1차 침입은 스테이지로 쓰지 않고 오프닝 회상으로만 둔다(챕터 제목 연도 1285~1288과 일치).
3. 쿠빌라이 칸은 전장에 나오지 않는다. 오프닝/엔딩의 서신·사신 장면 컷인(초상 사용)으로만 쓴다. DB 영웅 코드는 `kublai_khan`(wave3 계열 파일에서 확인, heroes.json 본표 적재 여부는 박백엔 확인).

### 1.3 사료 확인 필요 (사람 검수)
1. 소게투 전사 장소(쯔엉즈엉 / 떠이껫 / 함뜨), 함뜨·쯔엉즈엉 전투의 선후와 지휘관 배정. 불일치 시 s3 지휘관을 익명 부장으로 바꾸고 소게투는 대사에서만 언급.
2. 오마르·판제·오로치의 바익당 최후 (오마르 생포→송환 중 침몰 전승, 판제 사망, 오로치 불확실).
3. 토간 구리통 일화, 팜 응우라오 발견 일화, 쩐 꾸옥 또안 사망·깃발 일화, 옛끼에우·자뜨엉 실존성.
4. 번돈 전투에서 장원호의 정확한 행적, 쩐 칸즈의 직접 참전 규모.
5. 3차 때 쩐 녓똥이 바익당에 직접 있었는지(미확정이면 s10 비등장).
6. 한국어 표기 확정: 노이방(Nội Bàng)·카리(Khả Ly)·반끼엡·번돈 등 지명, 인명의 한자음/현지음 기준(몽골 인물은 원사 한자음 병기 여부).

## 2. 장 질문과 주인공

- 질문: 비워 둔 곳은 누구의 것인가. (도성도 곡식도 비우고 물러난 쪽이, 채운 쪽을 이기는 법)
- 주인공: 홍강 하류 포구의 뱃사람. 물때와 물길을 읽는 연락병으로 불려 나간다. 기록에는 남지 않는다. 쩐 왕조 쪽에서 보면 신분이 낮은 평민이고, 쩐 흥다오·쩐 칸즈·쩐 녓주엇 모두에게서 "당신 눈에는 어느 쪽 물이 보이느냐"는 식의 실무 질문을 받는다. 몽골 쪽에서도 길 안내를 요구받는 장면이 한 번 있다(s2).
- 전투와의 연결: s1 길목(내주는 시간), s2 나루(건너는 일), s4 빈 도성(채워도 못 쓰는 땅), s7 군량선(채우는 쪽의 약점), s9~s10 물때(드러나는 말뚝). 끝에서 답: 비워 두었기 때문에 물이 빠질 때를 기다릴 수 있었다.

## 4. 스테이지 카드

공통: 권장 Lv·수치·병력은 임밸런. 사료 병력 수치 비사용. 호위형 목표 없음(NPC 이동 호위 목표 0). 몽골 병종·스프라이트 기존 재사용. 이벤트 수: 스테이지당 2개(챕터 20개, 상태 변경형은 10~12개). 대사 초안은 편집자 모드 1회 반영한 짧은 초안이며 본문 작성 때 재설계 가능.

### ch25_s1 랑선 길목 (1285 정월, 방어)
- 비트: 사신이 길을 빌려 달라 했을 때 이미 거절한 쪽이 이제 길목 하나를 일곱 턴만 붙든다. 주인공은 흥다오의 후퇴 명령을 전달하는 연락병으로 와서 "왜 이기러 온 게 아닌가"를 묻는다.
- 목표: win_mode all. survive_turns(7) + 길목 구역 hold_zone. 문구: "일곱 턴 동안 길목을 지켜 본대의 후퇴 시간을 번다". 패배: 흥다오 격파 또는 남쪽 입구 구역을 적이 넘음("길목이 뚫리면 본대가 따라잡힌다").
- 아군: 쩐흥다오(`hero:tran_hung_dao`), 팜 응우라오(NPC 유닛), 주인공, 무명 궁수대. 적: 토간 선봉장(익명, invented), 몽골 경기병·궁기병·중갑 보병.
- 이벤트 E1 (T2 예고 -> T3 적 증원, T2 유형): 턴 2 예고 후 턴 3 기병 2기 서쪽 spawn.
  - 응우라오: "북쪽 길에 먼지가 섰습니다." / 흥다오: "기병이 먼저다. 길부터 좁혀라." 
- 이벤트 E2 (T6 후퇴 신호, T6 대사형, 턴 6 flag): 
  - 주인공: "비워도 됩니까." / 흥다오: "비워야 길이 늘어난다. 길이 길어지면 저들 곡식이 먼저 닳는다."
