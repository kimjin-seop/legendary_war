## 3. 정합 점검(정보 공개 순서 위반 0건 목표)

- 서고장: 3-4 post에서 지음이 처음 소개(최고 책임자, 임용 효력 서명), a3_end 시오리가 '대장상 공석, 부재 중 교정 담당 책임자가 직무 대행' 사실 선행, 4-3 post 시오리가 결재자 칸 사실 재확인, 4-4·4-5·엔딩에서 사용. 1-4 post 지음 줄은 '교정 담당 책임자가 서명하거나 서고장 권한을 대행하는 경우'로 정정(act1 version 4). 서고장은 끝까지 공석이며 엔딩 서명은 규정에 따른 자동 갱신.
- 정리 목록 장 수: 2-5(1장) -> 3-5(2장) -> 4-2(3장). 4-open에서 '세 장은 추정', 4-2에서 확정.
- 미복원 서가 수: 17(1막 끝) -> 15(2막 끝) -> 11(3막 끝) -> 최종 2(엔딩). 4-open '열하나'는 재진술.
- 지음 '제가.' 끝맺음: 2막 1회, 3막 1회, 4막 1회(에필로그). '추정입니다': 1막 e4, 2막 open, 3막 e4_pre, 4막 e3_pre에서 각 1회.
- 시오리: 메인 4개 파일 전부에서 대사 본문에 '메우다·채우다' 0건(Grep, `_note`에만 용어 설명). 자기 과거·글씨·정체 언급 0건.
- 허준 진료: 쪽의 주인에게만 지음에게 보고(3-open 5번째 개정), 3-2·3-5·4-2에서 일관 적용.
