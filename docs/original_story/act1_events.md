# 오리지널 메인 1막 ep1~ep5 전투 중 이벤트(cue) 제안 (초안 r2, 문기획 검토 반영)

작성: 송서사, 2026-11-03. 짝 파일: `docs/original_story/act1_scenes.json`(r2). 기준: ORIGINAL_STORY_SYNOPSIS r2 4절, CUTSCENE_SPEC(say/camera/sfx/shake/move/fire/set_flag/spawn, `on`=battle_start/turn:N/when). 형식은 SCENARIO_CH1_BATTLE_EVENTS.md를 따른다.
전부 오리지널 가상, 대사는 창작 대사(is_invented). 데이터(stages.rules.cues)에는 넣지 않았다(제안). 좌표는 맵 확정 전이라 `[?]`로 두고, 맵디자이너·임밸런이 확정한다. 화자는 장면 JSON과 같은 코드(`hero:npc_jieum` 지음, `hero:npc_jjogi` 쪽이, `hero:npc_red_pen` 사자, `caption` 지문). 유닛 참조 `<적A>` 등은 배치 확정 후 id로 치환.
효과음 키는 현재 확인되는 것만 사용: `sfx_battle_tick`(종이 넘김 대용), `sfx_battle_rumble`(책장 쓰러짐), `sfx_battle_fall`(문·서가 닫힘), `sfx_aura_pulse`(쪽 반응), `sfx_move_step`, `sfx_turn_enemy`. 종이·조명·종소리 전용 효과음은 없으므로 '연출 요청'에 둔다.

## 4. 시오리·용어·금지 표현 점검

- 시오리 '메우다/메운/채우다' 사용: 대사 0건(act1_scenes.json의 _note 금지 규칙 설명 1건만 검색에 걸림). 자기 과거·글씨 언급 0건.
- 시오리 줄은 전부 서고 기록 사실 진술 또는 목표·등급 안내. 추측 진술은 지음 줄('추정입니다')로 분리.

- 반복 개그: a1e1 '방금 확인했습니다' 1회, a1e1 post/a1e3 post '규정에 없음' 2회(위반 조항 없음 / 오늘 처음 쓰는 조항, 맥락 다름), a1_end '반려' 1회(open 보고 형식 회수).

## 5. 사람 확인·결정 요청 (r2 후 남은 항목)

1. 포트레이트와 npc 로스터 code(`npc_jieum`, `npc_jjogi`, `npc_red_pen`)는 미등록, 코드명은 임시.
2. 1-4 버티기 턴 수는 대사에서 '사십 분'으로만 암시. 실제 턴 수는 임밸런 확정(대사에 턴 수 숫자 없음).
3. 쪽이는 비전투 유닛으로 확정됐으나 2막 이후 쪽이가 전투 참여할지(영웅 행) 결정 필요. 1-3 후속 구현에서 판정이 필요해지면 재검토.
4. 문기획 Minor 8건 원문: 전달받지 못해 항목별 대조를 하지 못했다. 원문을 주시면 r3에서 대조.
5. 역사 사실 근거: 봉수 제도 정의 1줄(a1e5_post 시오리)만 accepted. 웹 대조는 하지 않았다. 1막 나머지는 전부 invented.
6. 미복원 서가 17의 이후 막 갱신 수치는 2막부터 지음 한 줄 보고로 확정(2막 작성 시 제안).
