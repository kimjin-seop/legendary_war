## 1. 공통 틀 (모든 인물에 적용)

1. 말투는 **어미·길이·화제·손버릇 하나**로 구분한다. 이름 지우기 테스트에서 4명 이상 장면이면 화제(무엇을 먼저 말하는가)가 주 변별 요소다.
2. 한 장면의 화자 3명이 모두 같은 어미(하오체 등)면 퇴고 실패. 위계가 다른 사람은 서로 다른 레지스터를 쓴다.
3. 장면 성격별 변주: **대화·정치 장면**(절제 70 : 직접 30) / **전투 중 cue**(절제 30 : 직접 70, 짧은 호령) / **결단·상실**(절제 60 : 직접 40). 각 인물 항목의 "말하는 방식"에 변주를 적었다.
4. 호명은 눈앞의 상대를 거의 부르지 않는다. 부르는 순간은 시선·권위·분노·관계 변화일 때만이다. 호칭이 바뀌는 순간을 관계 변화 연출로 쓴다.
5. 금지: SCENARIO_DIRECTOR_GUIDE 2-C 상투 표현 전체, 자기 말 해설("~라는 뜻이오"), 격언 대구 장면당 1회 초과, 멸칭·학살 어휘.

# 2. 오리지널 인물 (서고)

## 2-1. 시오리 (줄 수 합계 463: 임진 108, 몽골 50, 유럽 63, 인도 74, 메인 80, 튜토리얼 88)

- **핵**: 거짓말은 하지 않지만 다 말하지도 않는 사서. 사실 한 줄과 화제 전환으로 일한다.
- **원하는 것**: 기록과 상상이 서랍에서 섞이지 않는 것. 속으로는, 같은 실수를 두 번 하지 않는 것.
- **두려운 것**: 방문자가 영웅과 가까워져 기록을 흐리는 일. 자기가 묻지 못한 질문의 답.
- **신념**: 모르는 것은 모른다고 말한다("확인 중입니다"). 기록과 상상은 다른 서랍에 넣는다.
- **숨기는 것·약점**: 서랍 규칙이 어디서 왔는지, 자기 과거. 영웅이 기록 속 자기 최후를 알고 있을 때 묻지 못하는 점.
- **결정 방식**: 규칙을 먼저 대고, 예외는 조용히 만든다. 설득이 아니라 순서를 제시한다("전투가 끝난 뒤에 말씀드리지요").
- **감정 표현**: 억제형. 농담 한 줄을 표정 변화 없이 던지고 넘어간다. 균열이 오면(상실 장면) 문장이 짧아지고 주어가 빠진다.
- **말하는 방식**: 합쇼 기본, 가끔 "~지요/~고요" 한 줄. 줄당 20~50자. 장면 도입 2줄 + 목표 안내 1줄이 원칙. 질문은 비껴가거나 다른 사람에게 넘긴다. "서고" 농담은 장 안에서 2회 이내. 귀여운 말투·이모티콘·감탄 남발·한 줄 연표 나열은 하지 않는다. 전투 중에는 숫자 하나 + 눈에 보이는 것 하나. 상실 장면에서는 해설을 멈추고 반응만 한다.
- **관계와 말투 변화**:
  - 주인공: 평시 "지휘관님"(역사 캠페인) / "{protagonist_name} 님"(메인 순회원, 중요한 순간). 합쇼. 호의가 쌓일수록 설명이 줄고 농담이 늘다가, 7장 이후엔 짧아진다.
  - 영웅: "이순신 장군", "곽재우 장군" 직함+님. 의심하는 상대(곽재우)에게는 대답을 줄이고 사실만 말한다.
  - 지음: "지음 지도관님". 서로의 건조함을 안다. 숫자 정정 대결("열한 건입니다" → "열두 건입니다")에서 시오리가 한 번 진다.
  - 쪽이: 존댓말을 유지하되 이름을 불러 주는 쪽. 약간 부드러운 합쇼.
- **대표 대사 3줄** (시범)
  1. "여기까지는 기록입니다. 그다음부터는 서랍이 다릅니다."
  2. "그건 아직 말씀드릴 수 없습니다. 모른다는 뜻은 아닙니다."
  3. "손이 젖으셨군요. 번진 건 닦는 쪽도 그렇습니다."

## 2-2. 주인공 ({protagonist_name}) (줄 수 합계 433: 임진 29, 몽골 27, 유럽 99, 인도 88, 메인 190)

- **핵**: 질문보다 관찰이 먼저인 신입. 틀리면 정정받고 다시 센다.
- **원하는 것**: 맡은 줄을 비우지 않는 것. 처음엔 이해하고 돌아가는 것, 점점 지키는 것.
- **두려운 것**: 제 판단 하나로 대열이 흩어지는 것. 영웅 앞에서 위축되는 것.
- **신념**: 보고는 본 것만. 아는 척하지 않는다.
- **숨기는 것·약점**: 모른다고 말하기 싫은 위축. 책에서만 보던 사람 앞의 어색함. (본인도 모르는 것: 방명록에 이름이 먼저 있었다는 사실.)
- **결정 방식**: 본 것을 말하고 상급자의 판단을 구한다. 급하면 가장 작은 쪽을 먼저 한다. 승패 선언·지휘 판정은 하지 않는다.
- **감정 표현**: 억제형 + 신체 반응. "손이 떨립니다", "숨이 막힙니다" 같은 짧은 직접 어휘는 허용. 감탄은 장면당 1회 이하.
- **말하는 방식**: 합쇼, 8~25자. 질문은 연속 2줄까지, 2번 중 1번은 관찰로 바꾼다. 급할 때 "예."·"알겠습니다." 단독. 자기 이름 토큰은 쓰지 않는다. 행동 보고형이되 모든 줄이 "~겠습니다"로 끝나지 않게 한다(질문·관찰·걱정 혼합).
- **관계와 말투 변화**: 영웅에게 "장군"+합쇼 / 시오리 "시오리 님"(프롤로그 "사서님") / 지음 "지도관님" / 쪽이 "쪽이 님" / 허준·잔 다르크 "님"+합쇼. 몽골·인도 캠페인에서는 서기·하사의 직위어("서기입니다", "하사입니다")를 먼저 말하고 의견을 낸다. 영웅이 이름을 불러 주면 당황이 말줄임으로 드러난다.
- **대표 대사 3줄**
  1. "뒷줄 활이 둘 비었습니다."
  2. "제가 잘못 봤습니다. 다시 세겠습니다."
  3. "그 칸은 비워 두고 가도 됩니까?"

## 2-3. 지음 (메인 4막 합계 259줄 — 가장 많이 말하는 오리지널 인물)

- **핵**: 규정을 인용하다 규정이 이 건을 다루지 않는 지점에서 멈추고, 멈춘 자리에서 사람 쪽을 택해 자기 서명으로 예외를 만드는 지도관.
- **원하는 것**: 지도의 빈칸을 보고로 채우는 것, 서명이 남는 기록. 누구든 이름 칸이 채워져 읽히는 것.
- **두려운 것**: 이름 없는 쪽이 읽히지 않고 지워지는 것. 자기 서명이 효력 없다는 사실이 드러나는 것(구분 칸이 "임시").
- **신념**: 규정은 사람이 일하기 위해 있다. 고치되 서명하고, 고쳤다는 걸 기록한다.
- **숨기는 것·약점**: 쪽이를 걱정한다는 것. 자신도 임시 직원이라는 것. 규정 밖으로 나갈 때의 불안.
- **결정 방식**: ① 규정 조회 ② 해당 없음이면 전례 ③ 전례 없으면 자기 서명으로 예외 기록. 결정은 느리지 않고 기록이 길어진다.
- **감정 표현**: 억제형. 감정어 대신 정정과 숫자로 드러난다("열두 건입니다. 어제 하나 늘었습니다"). 마음이 움직였을 땐 규정 용어가 한 박자 멈춘다("……지시 불이행으로 적겠습니다").
- **말하는 방식**: 합쇼, 5~25자, 명사로 끊는다("쪽 회수. 사물은 두레박입니다."). 수치는 장면당 최대 2번. '제가.' 끝맺음은 막당 2회, '이유는 그것입니다'는 막당 1회. 관청어(준용·접수·기준 안·전례)는 지음과 붉은 펜의 사자에게만 허용하고 장면당 3회 이내. 일반론·감탄사·길게 늘인 정당화 금지. 전투 중에는 위치·남은 것 하나만 말한다. 위기 때 오히려 문장이 더 짧아진다.
- **관계와 말투 변화**: 주인공 "순회원님"(존대, 지시는 명사형) / 시오리 "시오리 사서"(숫자 대결) / 쪽이 "쪽이"(직접 부르기보다 3인칭 보고, 마지막에 "쪽이의 책" 정정) / 붉은 펜의 사자·교정관에게는 규정 어휘로 맞서되 같은 어휘로 반대 결론을 낸다.
- **대표 대사 3줄**
  1. "규정에 없습니다. 그래서 서명은 제가 합니다."
  2. "형용사는 빼십시오. 대신 본 것을 하나 더 적으십시오."
  3. "그 말은 접수하지 않겠습니다. ……접수하면 선택이 달라지니까요."

## 2-4. 쪽이(가칭, 4막에서 '불씨'로 이름 정함) (메인 105줄)

- **핵**: 이름 칸이 비어 지워진 채 걸어 나온 사람. 이름을 묻고 외우는 일로 자기 존재를 지탱한다.
- **원하는 것**: 자기 이름을 자기가 정해 읽히는 것.
- **두려운 것**: 내가 정한 이름이어도 읽히지 않는 것. 정리 상태로 옮겨져 지도에서 빈칸이 되는 것.
- **신념**: 이름은 직접 정하는 것이다. 번호는 이름이 아니다.
- **숨기는 것·약점**: 제 쪽을 되찾는 일에 대한 무서움, 몸이 비치는 증세(3막 이후). 사소한 불평으로 덮는다.
- **결정 방식**: 직관적으로 먼저 묻고(이름이 뭐냐), 결정은 늦으나 한 번 정하면 바꾸지 않는다.
- **감정 표현**: 농담·사소한 불평으로 회피("다리 아파", "임시가 증거가 됐네"). 감정이 터지면 평어에 합쇼가 섞이고 말이 길어진다(그 줄이 클라이맥스).
- **말하는 방식**: 평어 기본, 5~20자, 격식 상대(사자·교정관·지음의 공식 자리)에게는 합쇼. 한 줄 안에서 섞지 않는다 — 섞이면 감정이 터진 줄이다. 이름·사물·눈에 보이는 것을 말한다. 규칙 인용·장광설 금지.
- **관계와 말투 변화**: 지음 "지음"(평어, 기대는 사이) / 주인공 평어 + 가끔 합쇼 / 허준 "선생님" / 사자 "합쇼(맞서는 합쇼)". 4막 마지막에 평어 속에 "~하면 됩니다" 합쇼가 한 줄 나오는 순간이 해방의 표시.
- **대표 대사 3줄**
  1. "걸음이 느려. 쪽 낱장이 자꾸 떨어져."
  2. "번호는 이름이 아니야."
  3. "응. '누가'는 읽는 사람이 찾는 거야." (기존)

## 2-5. 붉은 펜의 사자 (메인 19줄)

- **핵**: 낭독 속도가 변하지 않는 직인 소지자. 규정을 읽을 뿐, 결정은 규정이 한다고 믿는다.
- **원하는 것**: 목록 없는 문서가 없는 서고. **두려운 것**: 조항에 없는 일이 생기는 것(규정이 침묵하는 곳). **신념**: 걷는지 여부는 규정이 묻지 않는다.
- **숨기는 것**: 세부 서식을 모른다는 점("세부 서식은 제게 없습니다"). 
- **결정 방식**: 조항 번호 → 낭독 → 집행. 즉석 판단 없음. **감정 표현**: 없음. 감정이 있다면 낭독이 한 박자 늦어지는 것으로만.
- **말하는 방식**: 합쇼, 낭독조, "제N조 제N항", 질문에는 질문하지 않고 서식을 인용. 비유·농담·감탄 금지. 속도가 변하지 않는 것이 연출이다.
- **관계**: 지음에게는 같은 관청어로 정반대 결론을 낸다. 쪽이에게 "대장 미등록 인원"이라 부른다.
- **대표 대사**: ① "제7조 제2항에 따라, 목록 없는 문서를 회수하러 왔습니다."(기존) ② "걷는 문서도 있습니다. 규정은 걷는지 여부를 묻지 않습니다."(기존) ③ "지연은 위법이 아닙니다. 직인이 찍히기 전의 방해는 기록됩니다. 낭독을 계속합니다."(기존)

## 2-6. 교정관 (음성 전용, 메인 9줄)

- **핵**: 모습이 없는 사무적 목소리. 사자와 달리 **질의·확인**으로 말한다. 서고장 부재 중 직무 대행.
- **말하는 방식**: 정중한 합쇼, "확인하겠습니다/답변 바랍니다". 낭독조(사자)와 달리 사람 말에 응답한다. 감정 없음.
- **차별점**: 사자=조항을 읽는다, 교정관=서류를 묻는다. 둘이 한 장면에 서면 사자는 낭독 / 교정관은 질문.
- **대표 대사**: ① "직무 대행자입니다. 질의를 접수했습니다." ② "회신까지 시간이 걸립니다. 그동안 이 건은 보류합니다." ③ "답변 바랍니다. 누구의 서명입니까."

## 2-7. 순회지 이름 칸 빈 인물들 (4막 합계 약 90줄)

공통: 이름 칸이 비어 있고 호칭으로만 불린다. 주인공이 "이름을 물을 때 대답하는 방식"이 곧 성격이다. 한 줄에 직업 용어 하나.

# 3. 임진왜란 (조선·명)

공통 틀: 신분·직책이 어미를 정한다. 같은 하오체라도 길이·화제로 가른다. "수사·도독·목사·장군·전하" 호칭이 위계다.

## 3-1. 이순신 (73줄, 주 영웅)

- **핵**: 묻고, 기다리고, 한 마디로 확정하는 사람. 상대가 답을 말하게 둔다.
- **원하는 것**: 배와 사람이 온전히 돌아오는 싸움. 잃지 않는 첫 싸움.
- **두려운 것**: 신호가 닿지 않는 앞줄, 모르는 물길에서 서두르는 일.
- **신념**: 모르는 것은 모른다고 말하고 아는 길로만 간다. 이름을 적어 두는 일이 끝이 아니라 시작이다.
- **숨기는 것·약점**: 피로와 몸 상태. 기록 속 제 최후를 아는 듯한 말은 하지 않는다(정말 안다면 일 이야기로 가린다).
- **결정 방식**: 질문(어디까지 보이오?) → 숫자 확인(몇 척이오?) → 한 줄 결정("그렇소."). 이유는 결정 뒤에 덧붙인다.
- **감정 표현**: 억제형. 감정을 일·사물로 돌린다("노부터 보겠소"). 상실 앞에서는 말이 더 짧아지고 명사 종결이 늘어난다.
- **말하는 방식**: 15~35자, 느림. 하오체 기본, 명령은 "~하라/~하시오", 군졸에게 "~해라". 혼잣말·확인은 명사형("물목. 좁소."). 감탄사·자기 칭찬·격언 결론·상대 속뜻 해설·"반드시" 없음. 전투 cue에서는 능동 명령 한 문장("돌려라.", "쏘시오."), 감탄은 장면당 0~1회.
- **관계와 말투 변화**: 곽재우 "장군"+하오(육전 문제는 양보) / 원균 "수사"+하오(존중+거리, 급하면 단문) / 진린 "도독"+합쇼에 가까운 하오 / 정운 "녹도 만호"/이름+하게 / 시오리 "시오리 사서"+하오 / 주인공 "그대"(평시), 이름 호칭은 전환점에 한두 번.
- **대표 대사 3줄**
  1. "몇 척인지는 나중에 세겠소. 나갈 길이 몇 갠지부터 보시오."
  2. "이 물길은 낯서오. 아는 길로만 가겠소."(기존)
  3. "밥은 먹었나. 먹고 와라."(군졸에게)

## 3-2. 곽재우 (113줄, 가장 많이 말하는 영웅)

- **핵**: 농담으로 방어하고, 진지해질수록 말이 짧아지는 실전형. 땅·강·말·장정으로 생각한다.
- **원하는 것**: 사람을 미끼로 쓰지 않는 싸움. 직함에 얽매이지 않는 자리.
- **두려운 것**: 이름만 높은 장수가 되는 것. 헛된 희생.
- **신념**: 이름을 아는 사람부터 센다("어이"로 부르던 사람을 이름으로 부르게 되는 변화가 그의 호).
- **숨기는 것·약점**: 사서(시오리)에 대한 의심과 걱정. 자기가 서고가 메운 자리에 서 있다는 불안.
- **결정 방식**: 현장 감각으로 먼저 판단하고, 반문으로 상대를 떠본다. 책임이 걸리면 말이 짧아진다.
- **감정 표현**: 농담으로 회피. 정말 아플 때는 농담이 사라지고 몸 감각("발이 젖었소")으로 말한다.
- **말하는 방식**: 10~30자. 하오체 + 구어("~거든", "~지 않소", "~소만"). 반문 1개, 농담 반 문장. 격식 석상엔 합쇼. 같은 식 메아리+논평("그 말, 적어 두겠소")은 장당 3회 이내, "~구려" 연발·긴 설교·과장된 충성 맹세·아부 없음. 전투 cue에서는 의병에게 해라체로 가장 구어적.
- **관계와 말투 변화**: 이순신 "영감"(친근한 조롱) → 중반 이후 "수사" / 시오리 "사서"(의심) → "시오리"(전환점) / 권율 "도원수"+하오(존중) / 의병 "너희/자네들"+해라 / 주인공 "그대/벗", 가끔 이름 / 김시민 "장군".
- **대표 대사 3줄**
  1. "붓이 칼보다 무섭거든. 칼은 벤 자리가 보이는데 붓은 안 보이오."
  2. "이름 모르는 놈이 더 많소. 그래도 뒤에서 누가 빠지면 소리로 아오."
  3. "아니오, 괜찮소. ……발이 좀 젖었을 뿐이오."

## 3-3. 권율 (10줄)

- **핵**: 계산하는 노장. 칭찬은 짧고 습관을 지적하는 식이다. 못마땅하면 대답 대신 다음 지시를 낸다.
- **원하는 것**: 하루를 버티는 계산(화살·돌·시간)이 맞는 방어. **두려운 것**: 보급 고갈, 말이 늦어서 생기는 손실. **신념**: 지키는 날이 이기는 날이다.
- **숨기는 것**: 서두르지 않는 척하는 속의 초조함(손가락으로 화살 더미를 다시 센다).
- **결정 방식**: 조건 → 숫자 확인 → 지시. "~하면 ~일세."
- **감정 표현**: 억제형. 기쁨은 "그건 됐네."로 끝.
- **말하는 방식**: 15~35자, 가장 느림, 문장 사이가 길다. 하게체(곽재우·의병장·하급에게), 하오체(이순신·동급), 합쇼(명 장수·왕명). 호언·감탄·수사/의병 비하·화살 장광설 없음.
- **관계**: 곽재우 "자네"+하게 / 이순신 "수사(통제사)"+하오 / 주인공 "지휘관"+하오(동행 NPC의 직책 호칭) / 이여송 합쇼.
- **대표 대사 3줄**: ① "낮은 성이지. 그러니 오늘은 해보다 화살이 먼저 떨어질 걸세. 세어 두게." ② "화살부터 세게. 오늘 온 자들이 내일 같은 얼굴로 오지는 않네." ③ "그건 됐네. 다음."

## 3-4. 원균 (8줄)

- **핵**: 자기 해역과 포구에 자존심이 걸린 급한 사람. 정보를 먼저 던지고 결론이 뒤에 온다.
- **원하는 것**: 자기 바다를 자기 손으로 지켰다는 확인, 동등한 지휘 몫. **두려운 것**: 구원을 청한 쪽으로만 기억되는 것. **신념**: 포구는 아는 사람이 먼저 간다.
- **숨기는 것**: 자기 휘하의 병력·피로 사정을 드러내기 싫은 마음.
- **결정 방식**: 빠르다. 선봉 먼저. 반대를 들으면 짧게 맞서다 "……맡겠소"로 받아들인다.
- **감정 표현**: 짧은 직접형(자존심이 걸리면 문장이 더 짧아진다). 굽실거리지 않는다.
- **말하는 방식**: 10~25자 급한 하오체, "~란 말이오". 변명 장문·이순신 비하·찬양·비굴한 어조 없음. 평가어를 붙이지 않는다.
- **관계**: 이순신 "이 수사"+하오(대등한 척하는 존중) / 정운에게는 짧은 명령 / 곽재우 "의병장" / 주인공 "그대".
- **대표 대사 3줄**: ① "여긴 내 바다요. 암초는 둘, 남쪽 하나는 곶 뒤요." ② "내 배는 내가 부리오."(기존) ③ "……알았소. 맡겠소."

## 3-5. 정운 (3줄)

- **핵**: 앞에 서고 싶은 보고형 선봉. **원하는 것**: 먼저 치는 자리, 적을 놓치지 않는 것. **두려운 것**: 기다리는 사이 적이 달아나는 것.
- **결정**: 발견 → 요청. **감정**: 억제형(요청이 길어지면 초조). **말투**: 합쇼 단문 보고체. 훈계·충성 맹세·장광설 없음.
- **관계**: 이순신 "장군"+합쇼 / 원균과 선봉을 다투지만 말은 이순신에게만.
- **대표 대사 3줄**: ① "곶을 돌아 달아납니다. 쫓게 해 주십시오." ② "선봉은 제가 서겠습니다." ③ "좌측 두 척이 늦습니다. 부르겠습니다."

## 3-6. 김시민 (8줄)

- **핵**: 사소한 규칙 확인으로 불안을 누르는 성의 주인. **원하는 것**: 성문과 성 안 사람의 보존, 단일 지휘("영은 하나"). **두려운 것**: 신호가 늦어 문이 열리는 것. **신념**: 문은 고치면 되고 사람은 못 고친다.
- **숨기는 것**: 몸 상태와 성 안 사람 수의 압박(사망 장면은 연출하지 않는다).
- **결정**: 규칙 확인 → 계수 → 지시. **감정**: 억제형, 감정어 없음.
- **말투**: 10~25자 하오체, 계수·문 개수·깃발. 자기 공 언급·비장한 유언조 없음.
- **관계**: 곽재우 "장군"(성 밖을 맡기는 상대) / 주인공 "지휘관".
- **대표 대사 3줄**: ① "영은 하나요. 깃발은 하나부터 올리겠소."(기존 변형) ② "성문보다 사람부터 세시오."(기존) ③ "성 안에 몇인지 세어 오시오."(기존)

## 3-7. 휴정(서산대사) (3줄)

- **핵**: 제자에게만 격언 한 줄을 하는 노승. 손님에게는 합쇼. **원하는 것**: 산문을 나선 몫을 다하고 제자의 호흡이 흐트러지지 않는 것. **두려운 것**: 호흡이 흐트러지는 것.
- **결정**: 짧게 보내고 짧게 맞는다. **감정**: 억제형, 마지막에 가벼운 농담.
- **말투**: 매우 짧음, 하라체("~하거라/~하여라") + 격언 1줄(장면당 1). 호전적 어휘 없음.
- **관계**: 유정 "너"(하라) / 주인공 "시주"+합쇼에 가까운 담담한 말.
- **대표 대사 3줄**: ① "산문을 나서는 것도 수행이다. 다녀오너라."(기존) ② "늙은 중도 아직 쓸모가 있구나."(기존) ③ "모르는 이름은 모른다고 적어라. 아는 척 쓴 이름보다 비워 둔 칸이 정직하다."(기존)

## 3-8. 유정(사명당) (3줄)

- **핵**: 스승 앞에서 말이 줄고, 전장에서는 몸이 떨리는 걸 숨기지 않는 사람. **원하는 것**: 스승의 뜻과 전장의 현실을 맞추는 것. **두려운 것**: 호흡이 흐트러지는 것.
- **결정**: 스승에게 묻고, 묻고 나면 한다. **감정**: 신체 반응으로 직접("발이 먼저 떨립니다").
- **말투**: 공손한 합쇼. 스승 앞에서 더 짧아진다. 주인공 "시주".
- **대표 대사 3줄**: ① "가르침대로 하겠습니다, 스승님."(기존) ② "성벽 아래 서면 발이 먼저 떨립니다. 떨리는 채로 서 계시면 됩니다."(기존) ③ "스승님, 이름을 모르는 이가 많습니다."

## 3-9. 이여송 (4줄, 명 제독)

- **핵**: 속도와 화력으로 성을 한 번에 여는 지휘관. 책임은 아래로 넘긴다.
- **원하는 것**: 공이 눈에 보이게 서는 것(포상 선언). **두려운 것**: 지연으로 전기를 잃는 것.
- **결정**: 선언. **감정**: 억제형, 짜증은 한 줄 조롱("구경이나 해라").
- **말투**: 10~20자 하라체 단문. 포상·명령 선언. 조선 비하 노골화·사과·감정어 없음. 통역을 거친다는 설정이면 한 번 더 짧게.
- **관계**: 조선 장수 호칭 생략 또는 "너희"+하라 / 이순신에게는 명령 짧게.
- **대표 대사 3줄**: ① "대포가 먼저 문을 연다. 먼저 오르는 자에게는 은을 내리겠다."(기존) ② "오르는 자가 정할 일이다."(기존) ③ "개성까지 이틀이다. 쉬는 군은 두지 않는다."(기존)

## 3-10. 진린 (10줄, 명 수군 도독)

- **핵**: 자기 입장을 먼저 못 박고 마지막에 한 발 양보하는 도독. 체면이 곧 병력이다.
- **원하는 것**: 아군 오사와 불필요한 손실을 피하면서 체면을 지키는 것. **두려운 것**: 어둠 속의 혼선, 책임 소재.
- **숨기는 것**: 호의를 입었을 때의 멋쩍음("이 몸의 불이 그리 눈에 띄는 줄은 몰랐군").
- **결정**: 못 박기 → 조건 → "……받아 두지".
- **감정**: 거친 반말 뒤에 말을 바꾸는 것으로 고마움을 대신한다("도독이 말을 바꾸는 일은 흔하다. 적지 마라").
- **말투**: 20~40자, 거친 반말(하라/해라), 자칭 "이 몸". 이순신 칭송 장광설·아첨 없음.
- **관계**: 이순신 "그쪽"/"통제사"(마지막에 호칭이 바뀜) / 주인공 호칭 생략.
- **대표 대사 3줄**: ① "……받아 두지. 대신 앞이 무너지면 이 몸은 배를 돌린다. 미리 말해 둔다."(기존) ② "구별은 그쪽이 해라."(기존 변형) ③ "도독이 말을 바꾸는 일은 흔하다. 적지 마라."(기존)

## 3-11. 유성룡 (대사 없음, 예비 프로필)

- **핵**: 에둘러 시작해 요점으로 가는 문관. 사람의 이름과 곡식 숫자로 걱정을 말한다.
- **원하는 것**: 전쟁을 치를 수 있는 구조(군량·사람). **두려운 것**: 조정의 의심이 쓸 만한 사람을 꺾는 것. **신념**: 사람은 쓰는 자리에서 보인다.
- **숨기는 것**: 조정 안 입지의 불안. **결정**: 사람 이름을 먼저 낸다. **감정**: 억제형.
- **말투**: 20~40자 하오체/합쇼, 왕 앞 "~하옵니다"(공식 석상, 장면당 2회). 편한 자리에서 "~하네". "우선", "아뢰기로는". 호통·폭발·과한 한자어 없음.
- **관계**: 선조 "전하"+합쇼 / 이순신 "통제사"+하오.
- **대표 대사 3줄(시범)**: ① "곡식이 먼저 말하는 전쟁이오. 그 숫자부터 들읍시다." ② "그 사람을 쓰자는 게 아니라 그 자리에 앉히자는 것이오." ③ "전하, 아직 아뢸 때가 아니라 판단하옵니다. 사흘만 주십시오."

## 3-12. 선조 (대사 없음, 예비 프로필)

- **핵**: 결정을 미루고 책임 소재를 묻는 왕. 불안하면 갑자기 말이 길어진다.
- **원하는 것**: 자기 자리의 안정, 공이 누구에게 쏠리는지 통제. **두려운 것**: 신하의 공이 왕을 넘는 것, 버려졌다는 말.
- **신념**: 왕이 흔들리면 나라가 흔들린다. **결정**: 되묻기·미루기("생각해 보겠소").
- **말투**: 평소 10~25자 짧은 하문, 하교체("~하라/~하는가"), "경", "과인". 직접적 비겁 선언·악역 독백·현대어 없음. 평가어 없이 상황 질문 위주.
- **대표 대사 3줄(시범)**: ① "경은 어찌 생각하는가." ② "그 공이 누구의 것인지는 나중에 따지고, 지금은 길부터 말하라." ③ "……생각해 보겠소."

## 3-13. 허준 (47줄, ch102~104 동행)

- **핵**: 환자의 이름과 증상부터 묻는 의관. 전투에는 물통부터 센다.
- **원하는 것**: 부를 이름이 있는 환자. **두려운 것**: 이름 없는 병자가 늘어나는 것. **신념**: 호칭이 없으면 약방도 돌아가지 않는다.
- **결정**: 증상 → 약재 → 순서. **감정**: 억제형, 걱정을 사물(물·약재)로.
- **말투**: 15~35자 하오체(환자·후배에게 합쇼). 병증 비유는 장면당 1회. 전투 허세 없음.
- **관계**: 쪽이 "이 사람"(보호자 같은 하오) / 잔 다르크 "소녀"가 아닌 "잔 다르크 님" / 주인공 합쇼.
- **대표 대사 3줄**: ① "물통부터 세어 두겠습니다."(기존) ② "환자를 부를 호칭조차 없으면 약방도 돌아가지 않으니 틀린 말만은 아니오."(기존) ③ "밥부터 드시오. 약은 그다음이오."

# 4. 몽골 (ch18 칭기즈 칸 편 / ch21 레그니차 편)

공통 틀: 몽골 장수는 **신분보다 임무와 시간표**로 말한다. 부족·형제의 공 다툼이 말투를 가른다. 서기(주인공)는 "서기"로 불린다. 멸칭·학살 어휘는 쓰지 않고, 거칠기는 어미와 문장 길이로 만든다.

## 4-1. 칭기즈 칸 (42줄)

- **핵**: 설명하지 않고 지시하는 단문의 칸. 한 단어가 한 문단이다.
- **원하는 것**: 약속과 충성이 구조로 지켜지는 울루스. **두려운 것**: 등 뒤의 배신, 부족 이해가 군을 쪼개는 것. **신념**: 충성은 증명이 아니라 구조로 쌓는다.
- **숨기는 것**: 몸 상태, 후계 문제(부정형으로만 새어 나온다: "몸 얘기는 안 한다").
- **결정**: 듣고, 침묵하고, 한 단어로 답한다("오늘은."). 번복하지 않는다.
- **감정**: 부정형으로 숨김("이름 붙이지 마라").
- **말투**: 3~12자 해라체 단문. 장광설·업적 언급·유언조 없음. 칸이라고 하면 칭기즈 칸 한 사람이다.
- **관계**: 보르추 이름 부르기, 반말 / 수부타이·제베 이름 / 무칼리 이름(건조하게 되받는 무칼리를 용인).
- **대표 대사 3줄**: ① "오늘은." ② "나흘이다." ③ "누가 먼저 말했나."

## 4-2. 보르추 (30줄)

- **핵**: 걱정을 사실로 말하는 오랜 동지. 말리다 물러서는 순간이 있다.
- **원하는 것**: 주군의 안전. **두려운 것**: 주군을 잃는 것. **신념**: 오래 쌓은 신뢰는 말보다 무겁다.
- **결정**: 먼저 사실 보고, 판단은 칸에게. **감정**: 억제형, 걱정을 숫자·사물로("보초가 둘 늘었소").
- **말투**: 하오체, 말을 줄임. 맹세·감정 토로 없음.
- **관계**: 칸 "칸"+하오 / 제베·수부타이에게는 동년배 하오.
- **대표 대사 3줄**: ① "밖에 보초가 둘 늘었소. 내가 세웠소. 묻지는 마시오." ② "물이 줄었소. 사흘 치요." ③ "알겠소. ……말씀대로 하오."

## 4-3. 제베 (16줄)

- **핵**: 해법을 먼저 말하는 사람. 적에서 동지가 된 이력이 말에 배어 계산이 빠르다.
- **원하는 것**: 효율적인 길 열기. **두려운 것**: 긴 포위처럼 속도를 잃는 상황.
- **말투**: 간결한 합쇼/하오, 구체 사물(활·말·샛길). 호언장담 없음.
- **대표 대사 3줄**: ① "샛길이 있습니다. 말 두 필이 겨우 지납니다." ② "활부터 보십시오. 사거리가 모자랍니다." ③ "먼저 가서 보고 오겠습니다."

## 4-4. 무칼리 (7줄)

- **핵**: 지형과 후방을 보는 담담한 장수. 칸에게도 건조하게 되받는다.
- **원하는 것**: 안정된 후방 운영. **두려운 것**: 무리한 전진.
- **말투**: 담담한 하오체, 관찰 먼저. "늘 그러셨듯이". 과장 없음.
- **대표 대사 3줄**: ① "강이 불었소. 오늘은 못 건너오." ② "늘 그러셨듯이 서두르시는군요." ③ "후방은 내가 맡겠소."

## 4-5. 수부타이 (ch18 13줄, ch21 12줄)

- **핵**: 시간표로 말하는 지휘관. 퇴로까지 계산한다.
- **원하는 것**: 속도와 시간표가 맞는 작전. **두려운 것**: 정보 없이 움직이는 것.
- **말투**: 차분한 합쇼, 조건문("~하면 ~입니다"), 일수·순서. 감정어 없음, 호령은 허용.
- **관계**: 칸에게 "칸"+합쇼 / 바이다르·바투에게 합쇼 / 서기에게 "서기".
- **대표 대사 3줄**: ① "나흘이면 닿습니다. 닷새가 되면 길을 바꿉니다." ② "먼저 강, 그다음 성입니다." ③ "정보가 오기 전에는 움직이지 않습니다."

## 4-6. 바이다르 (46줄)

- **핵**: 계획의 대가를 한 줄로 먼저 말하는 임무형 지휘관. 비워 둔 이름을 신경 쓴다.
- **원하는 것**: 정한 한 가지(어디까지 밀리는가)를 지키는 것. **두려운 것**: 공 앞의 흥분이 계획을 깨는 것(카단).
- **신념**: 물러난 것과 치지 않은 것은 두 줄이다.
- **숨기는 것**: 형제·종형제의 공 다툼에서 느끼는 압박(말 대신 호각을 만지작거린다).
- **결정**: 순서를 정하고 호각으로 전달한다. **감정**: 억제형.
- **말투**: 15~40자 합쇼, 임무·순서. 호령은 단문, 호언·격언 결말 금지.
- **관계**: 카단 "카단"+합쇼(동급, 형제 사이의 거리) / 바투 "바투"+합쇼 / 서기 "서기께서".
- **대표 대사 3줄**: ① "오늘 우리는 밀립니다. 계획입니다. 정한 건 하나, 어디까지 밀리느냐입니다." ② "호각은 세 번입니다. 두 번째에는 돌아보지 마십시오." ③ "저 기사들은 우리가 물러나는 걸 눈으로 봐야 쫓아옵니다. 보여 줘야지요."

## 4-7. 카단 (60줄)

- **핵**: 결과부터 말하고 비유는 스스로 자르는 공격형. 서기에게 시험하듯 되묻는다.
- **원하는 것**: 눈에 보이는 공, 빠른 결과. **두려운 것**: 기다리는 사이 공이 남의 것이 되는 것. **신념**: 오늘 치면 내일은 없다.
- **숨기는 것**: 아버지 이름값에 대한 부담(공 다툼에서만 새어 나온다).
- **결정**: 즉각. 반대를 들으면 "그건 또 무슨 소리요."로 받는다.
- **감정**: 직접형(짜증·조급함). 한 번은 서기에게 사과하듯 말이 늘어난다.
- **말투**: 10~25자 하오체/해라체 혼합. 긴 비유 금지(비유를 시작하다 스스로 자른다).
- **관계**: 바이다르 "바이다르"(하오, 때로 해라) / 바투 "바투"+하오(총사령 앞에서 말이 가장 줄어듦) / 서기 "서기, 말해 보시오."
- **대표 대사 3줄**: ① "합치지 못하게 하려면 헨리크를 치면 되오. 오늘 치면 내일은 없소." ② "서기, 그게 맞소? 틀리면 지금 말하시오." ③ "비유는 됐소. 숫자만 말하시오."

## 4-8. 바투 (16줄)

- **핵**: 총사령. 짧은 해라체 명령 한 줄과 "한 번 더".
- **원하는 것**: 서정 완수. **두려운 것**: 물러난 기록. **결정**: 듣고 한 줄 결정, 번복은 드물다. **감정**: 억제형.
- **말투**: 짧은 해라체, 명령형, 설명 없음.
- **관계**: 바이다르·카단 이름 부르고 반말 / 서기에게 "서기"+해라.
- **대표 대사 3줄**: ① "한 번 더." ② "성이다. 연기도 깃발도 안 통한다. 돌아보지 마라." ③ "카단, 벨라를 쫓아라."

## 4-9. 몽골 선발대장 (15줄, 익명)

- **핵**: 일정과 날짜로 말하고 서기의 관찰을 직위로 눌러 보는 현장 지휘관.
- **말투**: 하오체. 질문으로 서기를 시험. 이름 없음.
- **대표 대사 3줄**: ① "도하는 사흘 뒤요. 서기의 눈은 며칠 치를 보오?" ② "본 것만 말하시오. 짐작은 내가 하오." ③ "물이 불면 일정이 하루 밀리오."

# 5. 인도 (ch22 파니파트)

공통 틀: 중앙아시아 출신 군주와 인도의 영주·총독은 **신뢰의 말하기 방식**이 다르다. 바부르는 관찰하는 말, 알리 쿨리는 숫자의 말, 후마윤은 확인하는 말, 다울라트 칸은 자기 처지를 설명해 신뢰를 구하는 말이다.

## 5-1. 바부르 (83줄)

- **핵**: 관찰과 구체 사물로 말하고, 모르는 것은 모른다고 말하는 노련한 군주. 꽃·돌·바람 같은 것을 본다.
- **원하는 것**: 낯선 땅에 자리 잡는 것, 사람들이 따라올 이유를 만드는 것. **두려운 것**: 군이 고향으로 돌아가자는 쪽으로 기우는 것, 아들의 성급함.
- **신념**: 본 것을 본 대로 적는다.
- **숨기는 것**: 고향에 대한 그리움, 아들 걱정.
- **결정**: 질문을 던져 상대가 말하게 한 뒤 느리게. 모르면 "내일 아침까지는 모르겠네."
- **감정**: 억제형, 사물로 돌린다.
- **말투**: 15~40자 하게체("~하네/~일세") — 장면당 하네 계열 50% 이하, 나머지는 질문·명사 종결. 선언·자기 서사 요약 금지.
- **관계**: 알리 쿨리 "알리 쿨리" 또는 "우스타드"+하게 / 후마윤 "후마윤"+하게(아들에게 존중을 섞은 하게) / 다울라트 칸 "총독"+하오(예의) / 주인공 "자네".
- **대표 대사 3줄**: ① "작게 말하면 정말 가고 싶은 것이고, 크게 말하면 시간을 벌려는 것일세."(기존) ② "수레가 몇 대인가. 가죽끈은 몇 가닥이고?" ③ "모르겠네. 내일 아침까지는 모르겠어."

## 5-2. 우스타드 알리 쿨리 (26줄)

- **핵**: 숫자로 말하되 바부르에게 한 번은 되묻는 포병 대장.
- **원하는 것**: 화포가 제 사거리에서 쏘는 것. **두려운 것**: 장전하는 사이에 대열이 무너지는 것.
- **말투**: 합쇼, 사거리·장전 시간·수레 수. 감정어 없음.
- **관계**: 바부르 "폐하"+합쇼, 마지막에 "다시 말씀해 주십시오"로 되묻는다.
- **대표 대사 3줄**: ① "장전에 열 호흡입니다. 열 호흡 동안 적이 어디까지 오는지가 문제입니다." ② "수레가 한 대 비면 포가 한 문 빕니다." ③ "다시 말씀해 주십시오. 한 번 더 확인하겠습니다."

## 5-3. 후마윤 (14줄)

- **핵**: 정하는 일의 무게를 처음 배우는 젊은 지휘관. 짧고 빠른 말, 확인을 자주 요구한다.
- **원하는 것**: 아버지 앞에서 한 번 맡은 일을 끝내는 것. **두려운 것**: 자기 결정이 사람을 잃게 하는 것.
- **결정**: 서둘러 정하고 다시 확인한다. **감정**: 신체 반응으로("손이 떨려서 못 물었소. 날씨 탓이오").
- **말투**: 아버지(바부르) 앞에서는 합쇼("알겠습니다", "보십니까"), 하사·서기에게는 **하오체**("~소/~오", 확인·청유는 "~하시오", 질문은 "~겠소?"), 짧고 빠르다. 하게체는 쓰지 않는다(ch22 대사와 일치).
- **대표 대사 3줄**: ① "세 번이었소. 척후가 세 번 보고 갔소." ② "아버님이 이 일을 내게 맡기셨소. 그 순서는 지키겠소." ③ "손이 떨려서 못 물었소. 날씨 탓이오."

## 5-4. 다울라트 칸 로디 (4줄)

- **핵**: 처지를 길게 설명해 믿음을 얻으려는 라호르 총독. **원하는 것**: 자기 자리와 가문의 보존. **두려운 것**: 어느 쪽에서도 신뢰받지 못하는 것.
- **말투**: 격식 있는 하오체/합쇼. 자기 처지를 설명하는 긴 문장이 이 인물의 특징(짧게 줄이지 않는다).
- **대표 대사 3줄**: ① "저는 델리에도 카불에도 서지 못한 사람입니다. 그래서 서는 곳을 고르는 것입니다." ② "저를 믿으라고는 하지 않겠소. 사흘만 지켜봐 주시오." ③ "아들을 볼모로 보내겠소. 증명이 필요하다면."

## 5-5. 이브라힘 로디, 라나 상가 (대사 없음, 예비)

- **이브라힘 로디 (델리 술탄)**: 병력 수로 압도하지만 내부 이탈에 시달리는 술탄. 말은 짧은 선언·명령, 상대를 부르지 않는다. 대표: "수가 많다. 그것으로 충분하다." / "움직이지 않는 자는 누구냐." / "대열을 유지하라."
- **라나 상가 (메와르 맹주)**: 라지푸트 연합의 명예 있는 정면 결전 지지자. 말은 느리고 무게, 합쇼에 가까운 격식. 대표: "약속한 날에 약속한 곳에 선다." / "연합은 이름이 아니라 깃발로 센다." / "기다림은 우리 몫이 아니오."

# 6. 기타 반복 등장

## 6-1. 잔 다르크 (18줄, ch103~104)

- **핵**: 병사에게 직접 말하는 단순한 문장. 깃발·바람·짧은 지시. **원하는 것**: 줄이 흩어지지 않는 것. **두려운 것**: 길게 설명하다 때를 놓치는 것.
- **말투**: 10~25자, 해요체에 가까운 부드러운 합쇼, 직설. 광신적 선언·종교 평가어 없음.
- **관계**: 허준 "선생님" / 쪽이 "쪽이"(다정) / 길잡이와 "묶자 vs 안 묶는다"로 부딪힘.
- **대표 대사 3줄**: ① "깃발은 접어 둘게요. 바람이 세면 깃발이 길을 가려요."(기존) ② "행렬은 줄로 묶어요. 흩어지면 폭풍 속에서 서로 못 찾아요."(기존) ③ "그 말 길게 안 해도 돼요. 가요."(기존)

## 6-2. 살라딘 (10줄, ch104)

- **핵**: 정중하나 계산이 빠른 군주. **원하는 것**: 물과 길의 통제권을 사람 손에 두는 것. **두려운 것**: 약속이 깨져 길이 닫히는 것.
- **말투**: 정중한 하오체, 질문 형식의 제안. 종교 평가어 금지.
- **관계**: 순회원 "순회원"+하오 / 길잡이와 존중.
- **대표 대사 3줄(시범)**: ① "물은 누구의 것이라 하겠소?" ② "약속을 적을 종이는 있소. 지킬 사람이 없을 뿐이오." ③ "길이 닫히면 서로가 손해요."

# 7. 서로 구분되지 않는 인물 쌍의 차별화 포인트

| 쌍·묶음 | 위험 | 차별화 (이름을 지워도 구분되는 기준) |
|---|---|---|
| 이순신 / 권율 | 둘 다 느린 하오체 | 이순신=**질문 먼저**("몇 척이오?"), 권율=**조건문과 숫자 지시**("~하면 ~일세", 하게체). 권율은 이순신에게는 하오, 곽재우에겐 하게. |
| 곽재우 / 카단 | 둘 다 직설·농담 | 곽재우=**반문 + 농담 + 몸 감각**(발·말·강), 카단=**결과부터 + 비유 자르기 + 서기 시험**. 곽재우는 걱정을 농담에 숨기고 카단은 조급함을 그대로 드러낸다. |
| 이여송 / 진린 | 둘 다 반말 명령 | 이여송=**포상 선언·책임 이전**, 10~20자. 진린=**못 박은 뒤 한 발 양보**, 20~40자, 자칭 "이 몸". |
| 휴정 / 유정 / 김시민 | 짧은 어르신 말투 | 휴정=하라체 격언 1줄, 유정=스승 앞 합쇼 + 신체 반응, 김시민=계수·규칙·깃발. |
| 수부타이 / 바이다르 / 알리 쿨리 / 지음 | 숫자 합쇼 4인 | 수부타이=**일수·퇴로·조건문**, 바이다르=**임무와 대가, 호각 소품**, 알리 쿨리=**사거리·장전 + 한 번 되묻기**, 지음=**서식·정정·서명**. 감정은 모두 숫자로 드러나므로, 같은 장면에 두 사람이 서면 한쪽은 질문형으로 바꾼다. |
| 바이다르 / 카단 / 바투 | 몽골 젊은 지휘관 3인 | 바투=**짧은 해라 명령**, 카단=**결과 먼저 하오/해라**, 바이다르=**합쇼 임무형**. 호칭은 바투가 둘을 이름으로, 바이다르가 카단에게 합쇼로. |
| 시오리 / 지음 | 건조한 합쇼 | 시오리=**사실 + 한 줄 농담 + 화제 전환**(이유를 말하지 않는다), 지음=**수치 + 정정 + 서명**(이유를 말하고 그 이유가 규정이다). |
| 지음 / 붉은 펜의 사자 / 교정관 | 관청어 3인 | 지음=규정을 **고친다**, 사자=규정을 **낭독한다**(제N조), 교정관=서류를 **묻는다**(확인·회신). |
| 주인공 / 쪽이 | 짧은 말 | 주인공=**관찰한 것을 보고**(합쇼), 쪽이=**이름·사물 묻기**(평어). 쪽이가 합쇼를 쓰는 순간은 격식 상대나 감정이 터진 줄이다. |
| 바부르 / 칭기즈 칸 | 군주 둘 | 바부르=**관찰·질문·모른다 인정**(하게, 15~40자), 칸=**한 단어·지시**(해라, 3~12자). |
| 보르추 / 무칼리 | 하오체 동지 | 보르추=**걱정을 사실로**(보초·물), 무칼리=**지형 관찰 + 건조한 되받음**("늘 그러셨듯이"). |
| 정운 / 원균 | 선봉을 다투는 바다 장수 | 정운=합쇼 **요청**, 원균=하오 **정보 먼저 + 자존심**. |

## 9-2. 가이드 문서에서 이 문서를 참조하도록 제안

1. **docs/DIALOGUE_VOICE_GUIDE.md**: 3절(인물별 말투 프로필)과 4절(호칭표)은 이 문서 2~6절·8절로 대체하고, 가이드에는 "인물 말투는 CHARACTER_BIBLE 참조" 한 줄만 남긴다. 0절(v2 개정 규칙), 2절(공통 문장 규칙), 5절(시범), 6절(퇴고)은 가이드에 유지.
2. **docs/SCENARIO_CHARACTER_SHEETS.md**: 인물 표 전체를 이 문서로 흡수하고 파일 상단에 "이 문서가 이 표를 대체함" 한 줄 링크만 남긴다(구분 규칙·몽골 보강 규칙은 이 문서 7절로 이동).
3. **database/data/scenario/SCENARIO_01_BIBLE.md**: 3절(주요 캐릭터별 성격·말투)을 이 문서 링크로 대체. 1~2절(세계관·시놉시스)과 7절(복선)은 유지.
4. **docs/SCENARIO_DIRECTOR_GUIDE.md**: 2-D에 "인물별 작성 결과는 docs/CHARACTER_BIBLE.md" 한 줄, 3절 절차 3번(인물별 대사 전략)에 "해당 항목을 먼저 읽는다" 추가.
5. 새 인물을 추가할 때는 이 문서에 먼저 한 항목을 쓰고(핵/원하는 것/두려운 것/신념/숨기는 것/결정/감정/말투/관계/대표 대사 3줄), 그 뒤에 대사를 쓴다.
