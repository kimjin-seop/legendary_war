# 서가 시나리오 10 스테이지 확장 계획 (문기획 기획안 요약 + 팀장 결정, 2026-11-03)

요청(사용자): "시나리오가 짧은 게 있는데 적어도 10개 이상은 되어야 함. 그에 맞춰 시나리오나 맵 구성도 다시."
상세 후보 목록은 문기획 보고(세션 기록) 기준이며 송서사가 사료 대조 후 확정한다. 대사에는 사실/가설/각색 표기를 넣지 않는다.

## 팀장 기본 결정 (되돌리기 쉬운 쪽, 사용자가 바꿀 수 있음)
1. 범위: A안 = 서가 ch11~ch24 (ch1 임진은 이미 10). 메인 1~4막(각 5)과 ch999는 제외(사용자 확인 후).
2. 신규 스테이지 코드는 "후미 추가"(기존 코드 불변, s9 이후 또는 현재 마지막 번호 뒤). 중간 삽입 재번호 금지.
3. 신규 스테이지는 숨은 종장(ch999) 해금 필수 목록에 넣지 않는다(rules.optional=true). 해금 total 급증(약 90→160) 방지.
4. 파일럿: ch13(+7), ch20(+7)로 파이프라인 검증 후 나머지 서가 병렬.

## 박백엔 선행 작업 (공통)
- GameSeedShelf 코드 정규식 `ch{N}_s[1-8]` → s1~s12 확장(기존 동작 불변). ch18은 GameSeedCh18 별도(s1~s8만) → s9·s10 허용 또는 통합.
- 테스트 갱신: SeedShelfTest 고정 수치, SeedCh18Test assertCount(8).
- HiddenChapterService: rules.optional=true 스테이지는 필수에서 제외되는지 확인(이미 그렇게 동작).
- 진행도는 stage_id 기준 — 후미 추가만 하므로 영향 없음. 개발 DB 변경 전 백업.

## 확장 스테이지 시드 절차 (박백엔, 2026-11-03)
- `game:seed-shelf` 는 기본적으로 `*_ext*.json`(스테이지 `stages_ch{N}_*_ext*.json`, 로스터 `npc_roster_shelf_ch*_ext*.json`)을 읽지 않는다. 기존 시드·`ShelfSmokeTest` 등 기본 테스트는 확장 파일이 있어도 영향이 없다.
- `--with-ext` 를 주면 확장 파일을 포함한다. 확장 스테이지 중 `map` 이 DB `maps` 에 없는 것(과 그 선행 체인 후속)은 중단하지 않고 `확장 스테이지 건너뜀` 경고만 남긴다(비 ext 스테이지는 기존대로 맵이 없으면 중단). 모든 스테이지는 `rules.optional: true` 로 두어 숨은 종장 필수 해금에서 제외한다.
- 맵디자이너가 `maps_ch13_ext.json`/`maps_ch20_ext.json` 등을 만든 뒤의 절차:
  1. 개발 DB 파일 복사 백업(`docker/db-backup-20261103/`; compose 실행 전에 `--entrypoint ""` 로 파일 복사).
  2. `app/Console/Commands/GameSeedMapPack.php` 의 `ALLOWED`, `app/Support/ScaleUpMaps.php` 의 `FILES` 에 맵 파일명 등록.
  3. `php artisan game:seed-maps-pack --path=maps_ch13_ext.json` (파일별 반복; 기존 맵 재upsert 금지).
  4. `php artisan game:seed-shelf --chapters=13,20 --with-ext --with-npc --dry-run` 으로 경고(건너뜀) 0건 확인 후 `--dry-run` 없이 실행(이미 있는 스테이지는 건너뜀, 갱신은 `--update`).
  5. `game:audit-stages`, `game:map-check` 확인.
  6. 테스트: 기본 `ShelfSmokeTest`, 확장 포함은 `SHELF_SMOKE_EXT=1`(테스트 시드 목록 `tests/Feature/ShelfSmokeTest.php` 의 맵 파일 배열에 새 맵 파일 추가 필요) 로 실행.
