# ch21 전투 cue 대사 교정 비교 (DIALOGUE_CALIBRATION_CH21)

- 작성: 송서사, 2026-11-03. 계기: 사용자가 다른 AI의 ch21_s4/s5 cue 교정안을 "훨씬 자연스럽다"고 평가.
- 범위: 문서만. 데이터 파일(database/data/stages_ch21_*.json)은 수정하지 않았다. 아래 "합본 v2"는 **적용 후보**이며, 적용은 별도 지시 후 박백엔/윤프론 경로(타이밍·좌표 불변, say/caption 본문만 교체)로 한다.
- 출처 한계(중요): 타 AI 교정안 **전문은 받지 못했고 사용자 요지만** 받았다. 따옴표로 인용한 5개(카단, 주인공, 바이다르, 수부타이, 헨리크 2세)는 요지에 적힌 그대로이고, 나머지 열은 "요지 기반 재구성(추정)"이라고 표시했다. 전문을 받으면 해당 칸을 교체해야 한다.
- 대사는 전부 창작(is_invented). 사실 골격(날짜·장소·참전 세력)은 기존 caption의 근거 수준 표기를 유지한다. 근거 수준 전체는 기존 stages 파일의 _note/source 필드가 우선.

## 0. 총평 (편집자 모드)

타 AI 안이 좋은 점은 분명하다. (1) 전투 한가운데 대사에 **호령의 리듬과 발화 의도**가 있다. (2) 주인공이 숫자 보고만 하지 않고 눈앞의 변화에 반응한다. (3) caption이 장면을 보고 들을 수 있게 만든다. 현재 대사의 약점도 인정한다. "연기다. 이제 돈다." 같은 줄은 정보는 맞지만 전장의 숨이 없다. 이는 우리 가이드가 만든 문제이고(2부 참조), 취향 문제가 아니다.

반면 요지에 드러난 위험은 다음 다섯 가지다.

| 위험 | 예 | 왜 문제인가 |
|---|---|---|
| 사실 의미 변경 | "지원군이 당도할 때까지 고작 하루" | 원문은 "왕(바츨라프 1세)이 오기까지 하루"로 전승상 접근 거리(전승)이다. "당도할 때까지"는 내일 도착이 확정된 듯 읽힌다 |
| 해석을 사실로 단정 | "장막이 완전히 솟구쳐야" | 연막 여부는 해석(기존 cue 주석). "장막"이라는 명사가 연막을 확정한다 |
| 근거 수준 표기 삭제 | 괄호 제거 | (전승)/(각색)/(자료마다 다르다)는 개발 메모가 아니라 **독자용 사료 고지**. 개발 메모("연출 전용")만 빠져야 하고 사료 고지는 남아야 한다 |
| 편향/과격 어휘 | "이교도", "도륙", "놈들", "베어 넘겨라" | 중립 원칙 위반 소지. 몽골 장수가 적을 멸칭하면 근거 없는 성격 단정이 된다 |
| 감탄 남발·주인공 과열 | "낚였습니다!" 연발 | 서기(관찰자) 역할이 무너지고 주인공이 판정자가 된다. 느낌표가 연속되면 비장함 강요가 된다 |

또 하나, 요지 인용 5개를 보면 **모든 화자가 해라체/평서 단정으로 수렴**하는 경향이 있다(바이다르·수부타이는 원래 합쇼 설계). 구어성을 얻으면서 인물 구분을 잃는 교환이므로 합본에서는 어미를 되돌렸다.

표기: 합본 v2에서 ★ = 타 AI 안의 장점을 가장 많이 받은 것, ◎ = 현재안을 거의 유지(현재가 이미 양호), ▲ = 사실·표기 문제 때문에 타 AI 안을 크게 되돌린 것.
각 칸의 `!`는 개수를 센다.

## 2. 합본 v2 설계 원칙 (이번 비교에서 나온 것)

1. 타 AI 안에서 **받은 것**: 호령의 짧은 반복과 끝맺음, 구어 어휘(꾸물대지 마라, 지금입니다), 주인공의 눈앞 변화 반응, caption의 청각·시각 요소, 개발 메모 제거.
2. **되돌린 것**: 사실 의미(하루·연막·선발/본대), 사료 고지 괄호, 멸칭·과격어, 모든 화자의 해라체 수렴, 서기의 승패 판정.
3. 느낌표: 12개 대사 줄 중 합본 v2는 5개 줄에 각 1개(약 30%). 타 AI 안 요지의 인용 5줄은 줄당 1~2개(합계 8개 이상).
4. 주인공은 "관찰 + 짧은 걱정"이고 판정은 지휘관(바이다르·수부타이)이 한다.

## 3. 자기 비판: DIALOGUE_VOICE_GUIDE.md의 어떤 규칙이 "로봇 같음"을 만들었나

진단 자체(P1~P16)는 틀리지 않았다. 문제는 **처방이 한 방향(절제·건조)으로만 설계**되었고 장면 성격(대화 vs 전투 호령)을 구분하지 않은 점이다. 그 결과 전투 cue까지 "정보 한 줄, 감정 없음, 감탄 없음" 문체로 눌려 서류식 보고처럼 되었다.

| 가이드 규칙 | 원 의도 | 실제 부작용 (자기 비판) |
|---|---|---|
| 2-2 "한 줄 한 가지" + 2-1 줄 길이 상한(25~40자) | 설명 과밀 방지 | 줄이 계속 짧고 평평해 **리듬이 단조**. 상한만 있고 하한·변주가 없어 "짧은 단정문 연속"이 로봇 낭독처럼 들림 |
| 2-10 "두렵소/분하오/기쁘오 금지" + 지침 2-B "감정을 직접 설명하지 않는다" | 감정 해설(P11) 제거 | **해설과 직접 표현을 구분하지 않고 둘 다 막았다.** 사람은 위기에서 "빨리!" "위험합니다" 같은 직접 어휘를 쓴다. 전투 cue에서 감정이 사라짐 |
| 3절 프로필의 "절대 안 쓰는: 감탄사"(이순신·권율·곽재우·수부타이 등) | 허세·과장 방지 | 호령·경고의 감탄조차 막아 **전투 목소리가 없어짐**. 전장은 큰 소리가 나는 곳이다 |
| 3-3 "수부타이/바이다르: 감정어·호언 금지" | 냉정한 지휘관 | 냉정 = 무표정으로 해석되어 **긴박함이 사라짐**. 냉정한 지휘관도 호령은 한다 |
| 2-8 질문 비껴가기 / 2-11 "건조함은 어휘로" / 2-13 숫자 상한 | 서류식 Q&A, 숫자 과잉 방지 | 전투 cue에서 보고가 필요한데도 "질문에 답하지 않기", "숫자 최소"를 적용해 **전투 정보가 대사에서 빠지고** 나머지가 모호한 문장이 됨 |
| 3-2 주인공 "영웅적 선언 금지, 질문 2번에 1번" | 주인공 인터페이스화 방지 | 반응 어휘 자체를 줄여 **주인공이 무감각한 계측기**처럼 말함 |
| 6절 체크리스트 전체 | 반복 오류 방지 | 항목이 전부 "빼기"여서 **채점을 통과할수록 평평해짐**. 생동감을 확인하는 항목이 없음 |
| 전체 | - | 규칙이 pre/post 대화(ch1 정독)에서 도출되었는데 **cue 계열을 별도로 보지 않았다**. 5절 시범 12개도 pre/post뿐이고 cue 시범이 없음 |

한 줄 요약: **"해설 금지"가 "감정 금지"로, "허세 금지"가 "소리 금지"로 번졌다.** 지침 2-B의 "필요한 말만"을 문자 그대로 읽고 줄이는 쪽으로만 퇴고한 편집 습관도 원인이다.

## 4. 개정 규칙안 (10개)

기존 DIALOGUE_VOICE_GUIDE의 2절·3절·6절에 덧붙이거나 대체한다(승인 후 반영). 지침 문서(SCENARIO_DIRECTOR_GUIDE)의 금지 상투 목록은 그대로 유지한다.

1. **장면 성격별 절제/직접 비율.** 장면을 세 종류로 나눠 비율을 정한다. (가) pre/post 대화·정치 장면: 절제 70 : 직접 30, 속뜻은 행동·사물로. (나) 전투 중 cue(호령·보고·경고): 절제 30 : 직접 70, 짧은 직접 어휘 허용. (다) 결단·상실 장면: 절제 60 : 직접 40. 장면 메타(_note)에 종류를 적는다.
2. **전투 cue 허용 범위.** 짧은 호령, 감탄, 구어, 반복("돈다. 돌아라!")을 허용한다. 한 줄 최대 2문장·35자 안팎, 명령은 능동형 동사로 끝낸다. "~하는 것입니다" 같은 서술 종결 연속은 피한다.
3. **느낌표 상한.** 전투 cue 장면당 대사 줄의 30% 이하, 한 줄 1개, 2줄 연속 금지. pre/post는 장면당 2개 이하. 주인공 줄은 장면당 1개 이하. 사료 고지(caption)에는 쓰지 않는다. 지휘관의 호령 한 줄에만 몰아 쓴다.
4. **같은 정보도 행동·감각으로.** 보고는 "눈에 보이는 것 + 귀에 들리는 것 + 숫자 하나" 중 둘을 담는다(예: "활 두 번 거리! 앞줄이 보병을 두고 나갑니다"). 판단 어휘("성공했다/낚였다")는 지휘관에게만 둔다. 서기는 관찰한다.
5. **감정: 해설은 금지, 직접 표현은 허용.** "~해서 분하오/내 마음은 ~다"처럼 자기 감정이나 타인의 속뜻을 **분석·해설**하는 줄은 계속 금지. 대신 "빨리!", "위험합니다", "숨이 막힙니다", "손이 떨립니다" 같은 짧은 직접 어휘·신체 반응은 허용한다(2-10 개정).
6. **사실 보존 점검(교정 시 의무).** 대사를 고칠 때 아래 다섯 가지가 원문과 같은지 확인하고 변경 시 사유를 기록한다. (a) 시간·거리("하루", "활 두 번") (b) 주어(누가 오는가, 누가 이겼는가) (c) 확정 정도(전승/해석을 단정으로 바꾸지 않음) (d) 숫자 (e) 인과. "당도할 때까지", "장막" 같은 **명사 교체가 의미를 바꾸는 경우**를 특히 점검한다.
7. **개발 메모와 사료 고지 분리.** 괄호 안 내용을 두 종류로 구분한다. 개발 메모("연출 전용", "엔진 지원 전")는 대사/캡션에서 빼서 _note로 보낸다. 사료 고지("전승", "각색", "자료마다 다르다", "대사는 전부 창작")는 독자용 문장으로 유지하되, 길어지면 "~는 자료로 확정되지 않았다" 같은 문장 한 줄로 쓴다.
8. **어휘 중립.** 적군에 대한 멸칭(놈들, 이교도, 짐승 등)과 학살 어휘(도륙, 베어 넘겨라, 씨를 말려라)는 금지한다. 거친 강도는 어휘가 아니라 **어미(해라체/명령형)와 짧은 문장**으로 만든다. 종교·민족을 적의 속성으로 부르지 않는다.
9. **호령에서도 말투 유지.** 전투 cue를 구어로 바꿀 때 인물별 어미를 유지한다. 바이다르·수부타이는 합쇼 단문, 카단은 하오/해라 혼합, 바투는 해라체, 헨리크 2세는 하오+하라(군주). 같은 장면에서 화자 3명이 모두 해라체이면 퇴고 실패로 본다. 이름을 지워도 화자가 구분되는지를 6절 1번 기준으로 cue에도 적용한다.
10. **주인공 흥분 상한과 퇴고 항목 개정.** 주인공(서기)은 관찰·보고·걱정을 하되 승패 선언과 지휘 판정을 하지 않는다. 감탄은 장면당 1회. 6절 체크리스트에는 "빼기" 항목만 있었으므로 **생동감 항목 3개를 추가**한다. (가) 소리 내어 읽을 때 호령이 호령처럼 들리는가 (나) 장면의 가장 긴박한 줄에 직접 어휘가 있는가 (다) 모든 줄이 같은 길이·같은 어미로 끝나지 않는가. 기존 2-1 줄 길이는 상한만 있던 것을 "연속 3줄이 같은 길이대(±5자)이면 변주" 규칙으로 보완한다.
