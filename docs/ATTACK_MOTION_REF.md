# 공격 모션 참고 스펙 (영상 프레임 관찰 기반)

작성: 하플레이(플레이 테스터). 대상: 윤프론이 `BattleCutscene.js` 와 맵 위 공격 모션에 적용할 때 참고.
앱 코드·DB는 수정하지 않았고 이 문서만 작성함.

## 0. 관찰 방법과 신뢰도

- 출처 영상 (모두 유튜브 쇼츠, 세로 영상 428x761로 재생, 영상 속 전투 화면은 가로 띠 형태):
  - 영상 A: https://youtube.com/shorts/z8biYe5bpoA (랑그릿사 새턴판, 길이 59.9초). 보병 영웅 7~8초, 마법사 45~47초, 영웅끼리 52~53초 구간.
  - 영상 B: https://www.youtube.com/shorts/HZyQ5-hj6Wg 궁병 15~19초 구간.
  - 영상 C: https://www.youtube.com/shorts/qZQRCxd2AYU 일반 보병 부대끼리 3~5초 구간.
- 방법: Playwright(Edge headless)로 영상을 일시정지하고 `currentTime` 을 50~100ms 간격으로 옮기며 비디오 요소를 캡처. 시간값은 영상 재생 시각(초) 기준이며, 실제 영상의 프레임 사이 간격은 표본 간격(50~100ms) 이하로는 알 수 없음. ms 값은 모두 약 ±50ms 오차가 있는 추정치.
- 영상은 압축된 화면 녹화라 히트스톱(수십 ms 정지)과 한두 프레임짜리 플래시는 놓쳤을 수 있음. "관찰 안 됨"은 "없음"이 아니라 "해당 표본 간격에서는 안 보임"을 뜻함.
- 영상의 병사 스프라이트는 한 부대가 3개(보병 3, 시안 영웅 포함)로 그려지고, 이쪽 게임의 10기 대형과 다름. 아래 수치 중 위치는 "전투 화면 가로 폭 대비 비율"로 적었음. 이쪽 게임은 컷신 화면이 1280x720 전체이고 하단 패널이 얇으므로 비율을 그대로 환산할 것.

## 8. 이쪽 게임 적용 시 참고

- 이쪽 게임 컷신은 이미 대치 → 돌진 → 숫자 갱신 → 복귀 구조임(`플레이 테스트`에서 확인: 내 공격 약 4.5초, 상성 대등 전투에서 좌측 영웅 컷인 1명만 표시, 하단 패널 얇음). 영상 대비 가장 큰 차이는 영상은 병사가 위로 튕겨 사라지고 이쪽은 숫자만 갱신된다는 점이므로, 타격 순간 "적 병사 스프라이트 상향 이탈(200ms)"을 추가하면 영상의 타격감과 가장 가까움.
- 영상에는 화면 흔들림·화이트 플래시가 거의 없으므로, 추가하면 "영상 그대로"에서 벗어남. 필요하면 사용자 확인 후 추가.
- 구현 값(ms)은 전부 영상 관찰 추정이며, 정확한 프레임 단위 검증이 필요하면 영상 원본 프레임(30fps) 추출이 가능한 도구(ffmpeg 등)가 필요함.

## 9. 미확인 항목

- 영상 A 보병 영웅 구간에서 영웅 본체(대열 중 영웅 스프라이트)와 소속 병사의 개별 구분.
- 영웅끼리 교전에서 선공·반격 순서(양쪽 동시 돌진이라 구분 불가).
- 궁병: 목표 부대의 개별 쓰러짐 모션(영상 요소 하단이 잘림).
- 일반 보병끼리: 병사 개별 공방 모션(스프라이트가 작고 겹침).
- 사운드(효과음)는 평가하지 않음(재생 불가).
