# stage_02~06 대사 근거 메모 (송서사, 2026-11-14) — 화면 비노출 내부 문서

대상: `database/data/ch30_legacy_stages.json`. 근거 수준: confirmed(1차 사료·정설) / accepted(통설·후대 사서 다수) / verify(출처 재확인 필요) / invented(창작 대사·연출). 대사 자체는 모두 창작 대사이며, 아래는 대사가 기대는 사실만 정리한다.

## 공통 창작 장치
- 대출 장부(빌림·반납) 모티프: invented. 서고 사서라는 가이드 설정에서 온 장치이며 역사 주장 아님.
- 주인공이 적 지휘관과 직접 대화하는 상황 전체: invented(서고 설정).

| (제거됨) 한니발 병사의 식사·기름 서술 | verify | 2차 개정에서 대사에서 삭제. 남은 것은 "오늘 먹었소? / 허기진 장수는 판단이 짧소"라는 인물의 말버릇(창작)뿐이며 사료 주장 아님 |

- "중앙을 물린다"류 연출은 사용하지 않았고, "한 걸음 물러서 보이겠소"는 창작 도발 대사(트레비아의 실제 전술 아님).

## 2차 개정(2026-11-14) 사실 의존 변경
- 분량 확대로 늘어난 서술은 대부분 나레이션·말버릇·농담(창작)이며, 새 사실 의존은 다음뿐: 알렉산드로스 "스승·호메로스 사본·칼" (기존), 제갈량 "곡식 수송 부담"(기존 accepted), 한니발 "누미디아 기병·소문의 값"(기존), 칭기즈 칸 "예비마·자모카"(기존).
- 전투 cue의 "아우가 이 장면을 못 보는 게 아쉽소"(한니발)는 동생 마고가 트레비아에서 별동대를 맡았다는 서술(폴리비오스 3.71)에 기댄 창작 감정선. 별동대 규모는 사료별 차이가 있어 대사에서 언급하지 않음.
- 알렉산드로스 "성 앞 바다를 메우고 간다": 티레 방파제 일화(아리아노스 2.18–24, confirmed).
- 광개토대왕 "척후가 돌아왔다": 창작 도발 대사.

## 사람 확인 필요 (2차 개정 후)
1. 제갈량·한니발의 사료 해석 표현은 단정을 뺐으나, 한니발 "한 마리" 연출이 장면 시점(트레비아 전)에 놓여도 무리가 없는지 역사 자문을 한 번 받으면 좋음(낮은 우선순위).
